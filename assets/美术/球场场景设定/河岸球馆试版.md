# 河岸球馆试版

改场地前的可运行版本为 GitHub main 上的提交 `54c54a8`。本次从[河岸球馆概念草图](晚风球社-河岸球馆-概念草图01.png)制作，采用珊瑚红上衣、青绿短裤的近方球员，以及从球员背后看过球网的低机位。

馆内采用可产生视差的三维木拱、木地板、饮料亭、花箱和看台。桥、山、渡船与河岸使用单独的[远景画](../../../code/Clients/iOS/Resources/RiversidePanorama.jpg)。场地的比赛边界和球网高度沿用原尺寸。普通显示的基础镜头高度调至 2.35 米，俯角调至 10°；遇到后场高球和靠近画面边缘的落点环，镜头按需后移。减弱动态效果模式保留固定宽景。
