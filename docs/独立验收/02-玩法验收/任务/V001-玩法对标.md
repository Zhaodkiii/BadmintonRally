## 对标依据

- 下手上挑可解杀、以高弧线争取回位时间。上手下挥可压球；对高而晃的来球可打出更强的杀球。挥向可选择左右。任天堂官网刊载的入门教材逐项展示了这些轨迹。[官方玩法教材](https://www.nintendo.com/jp/ichikara/as8sa/02_en.html)
- 任天堂建议球刚过最高点开始下降时向下挥，打出快速杀球。按住 ZR 或 ZL 轻挥可放短，短球落前场，和杀球交替可改变回合节奏。官方没有给出毫秒窗口，本单的偏移量仅用于工程扫描。[官方技巧](https://www.nintendo.com/us/whatsnew/tips-and-tricks-for-nintendo-switch-sports/) · [官方项目页](https://www.nintendo.com/sg/switch/as8s/badminton/index.html)
- 失准的击球可能送出晃球，对手因此获得进攻机会。本作对标这条连续回合因果；本作保留实体音量键确认时刻，挥向与力度控制回法，使用现有屏幕预选放网时另行标注。[官方技巧中的羽毛球章节](https://www.nintendo.com/en-za/News/2023/April/Nintendo-Switch-Sports-Tips-and-Tricks-2380312.html)

## 真机复测矩阵

固定来球从“场景采集 → 固定来球”进入，另从首页“开始比赛”复验生产入口。每个变体至少重放三次，保留失败球。锁定包版本、角色、持拍手、来球世界轨迹、起始站位及游戏时钟；每次仅改表中列出的变量。用同一输入记录回放做单变量对照，再以实体音量键重复。每球保存场次/球次、来球类型、按下与裁决时间、按前 IMU、球与拍床坐标、过网高度、落点或拦截点、飞行时间、得分原因和录像帧。无实际落地的回合单列预测落点。

| 编号与固定条件 | 操作变化 | 可复查的通过条件 |
|---|---|---|
| G1 网前低点同球、同一次向前短挡 | 仅改变站位，A 近身、B 远半步、C 超出伸拍；三次均在同一游戏时刻按键 | A 短挡，B 跨步挡，两球拍床触球且过网后落前场；C 收拍、原球继续，无回球。并列背面与侧面帧。 |
| G2 到位后场高球，同一站位 | 同一时刻分别上挑、轻吊、向下扣；另用相同下挥重放在过顶前、下降初期可达点、落地后按键 | 高球弧顶高且落点深，吊球落前场，扣杀更快下压。记录每次相对弧顶及相对可达时刻的毫秒数。过高和落地后的尝试均保留原因。 |
| G3 中场接杀 | 同球同刻分别短幅卸力、向上托、水平向前反抽，均按键 | 分别获得近网短球、高弧解围、较平快的反击；逐球记录轨迹与对手接下一拍前的可用时间。 |
| G4 进攻机会 | 匹配可达高度和站位，比较普通高球与高晃球的同一下挥；另从失准回球连续追到下一拍 | 高晃球的进攻比普通扣杀更快或更强，录像能辨识机会。连续两拍日志能回溯该机会源自哪次回球。 |
| G5 贴网慢球 | 同球同刻同力度，向直线或对角挥；再固定挥向，以低、中、高三档力度回同一球 | 直线与对角终点可分；同一回法下三档实测深度或速度依次变化。贴带、下网、出界保留终止位置及实际得失分。 |
| G6 相同一颗可接来球 | 只挥不按；＋和−各单按；长按到松开；球已飞出再按；暂停时按并在恢复后再接 | 无按键零回球，每次单按最多一次尝试，长按无连发，飞出无二次改向，恢复后无残留输入。两键分别记录。 |
| G7 同一颗中场球 | 围绕基准可达时刻取 −100、−50、0、+50、+100 ms；按键前波形固定，左右手分别跑 | 输出真实裁决时刻、高度、触达结果与球路；早晚差异可由球和拍床的位置解释。边界内的合法回球允许不同深浅；越界时明确挥空。 |
| G8 首页正式单打 | 连续完成四类发球、接发、多拍、得分、换发、结算；同构建用本机屏和投屏各测 | 把单打的开始与结算关联到同一场次；逐球核对规则和比分。分别报告按键到首个可见反馈的逐次延迟、帧率与样本数。 |

扩展覆盖以 [场景与回法定义](../../../../code/Clients/iOS/Game/Rally.swift) 中 netHigh、netSlow、netLow、flat、defense、halfHigh、high、deepDrive、backhand 九组为准。每组的三种回法分别记意图、实际轨迹与失败数，共 27 格；四种发球分别记正手高远、正手短发、反手短发、反手偷后场的实际发球区、落点和裁决。按命名枚举数填满表不足以证明玩家能自主打出这些回法。
