# P005 四球截断盲审初判

观察材料为《Mac离线-修后-截断.mp4》，由 Mac 离线引擎输出。仅查看该片，按出现顺序独立记录。采用抽帧，先看整段动作，再逐帧看每段切黑前的最后六帧。以下左右均为画面方向。

| 球序 | 初判 | 看见的动作 |
| --- | --- | --- |
| 1 | 倾向击中，信心低 | 球员把拍举到头部右侧。来球落向拍尖，随后球与拍头连续数帧重叠，手臂开始回落。切黑前球仍朝原方向下落，看不到离拍后的回程。 |
| 2 | 不清楚 | 球员向头部左侧举拍，拍尖起初低于球，最后一帧才几乎接上。球与身体并未拉开明显的横向距离，无法凭姿势看出球会擦过还是被接住。 |
| 3 | 不清楚 | 球员在身体右前方抬高手臂，球在拍头上方，间隙一直缩小，最后几乎相贴。看不到球越过拍面，也看不到它转向。 |
| 4 | 倾向击中，信心低 | 拍头在身体左侧迎球，球与拍头轮廓连续重叠，随后手肘下降，另一只手张开。球仍向近场移动，不能确认接触。 |

四球都没有清楚显示拍头扫过之后球独自穿过空隙，因而没有一球能有把握判为挥空。第 1、4 球给人击中印象的依据是重叠持续较久。仅凭这段侧后方投影，无法确认拍与球在场地纵深上是否相遇。
