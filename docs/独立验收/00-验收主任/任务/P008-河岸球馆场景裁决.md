# P008 河岸球馆场景独立裁决

验收目标是正式比赛中的三维空间关系、近远球员和可读的飞行走廊。指定运行设备为 iPhone 18 Pro 模拟器（iOS 27.2）。

候选预检发现红店铺门面横跨场地中轴，在实际比赛画面中直接挡住远端球员。已通知制作负责人返修。最终候选待冻结录制。

## 返修核验

[预检退回帧](P008-证据/退回-店铺遮挡.jpg) 中店铺直接遮挡接球方。冻结构建的[首拍原图](P008-证据/正式单打/首拍-设备原图.png)及 [3 比 1 后场原图](P008-证据/正式单打/后场-设备原图.png) 中，店铺在网柱外侧，远方球员和中线可见。

两张原图等比缩小至 1080 像素宽，匹配店面、山墙和渡轮的静态细节。镜头换位时，三者水平位移分别为 22.53、9.40 和 4.46 像素，各有 180、393 和 28 个一致匹配。它们在比赛画面中产生了从近到远递减的位移。该测量包含机位朝向变化，不能由此反推各物体的实际距离。[实测数据](P008-证据/正式单打/实景两帧位移.json)

## 美术相似度判定

- 横向分区、连续屋架、玻璃端墙、旗串、店铺、本方珊瑚上衣与青绿短裤，以及球场上的前后景层次均可从正式比赛帧辨认。两侧表演空间与球路分离。
- 参考图约为 16:9，模拟器正式画面更宽。在首拍原图中，近方球员从发顶到鞋底约占画高 36%，草图准备姿势约为 40%。远端球员在本局发球阶段靠前，所占画高也较草图中的后场球员大。游戏中两方站位随实际来球和发球区变化。
- 手绘店铺与场馆后墙表面较细腻，木拱侧面、坐席边沿和人体轮廓仍明显更硬。部分花瓣在近景仍能看出重复形状，场边缺少草图那种长投影和斑驳反光。观众为静态坐姿，未观察到喝彩、转头等环境动画。此版可以用于实场体验反馈；逐像素复刻、全景自由漫游、全套动作完成度均不在本次签发范围。
