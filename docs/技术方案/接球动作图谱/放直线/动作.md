# 放直线

贴网慢球。本项观察目标为用同握力改打勾对角，比较过网横坐标。

## 动作流程

```mermaid
flowchart LR
    A["准备 · 将持拍肩对准同侧网口"] --> B["引拍 · 轻移重心"] --> C["击球 · 以小幅向前托送将球沿本侧过网"] --> D["收拍 · 随挥保持线路"]
```

1. **准备**　将持拍肩对准同侧网口。
2. **引拍**　轻移重心，拍头靠近来球线路。
3. **击球**　以小幅向前托送将球沿本侧过网。
4. **收拍**　随挥保持线路，持拍脚制动。

## 游戏中的动作与球路

![按键前后连续画面中的四个时刻](游戏阶段.png)

右手、60 帧/秒的固定来球测试中，玩家目标是**放直线**，引擎根据输入与击球点给出的回法是**放直线**。触球前后相邻两帧，手肘移动 6.9 厘米。同一合成输入在基线的握点跳变量为 10.4 厘米，本轮为 3.6 厘米。位移按人物局部坐标计算。

![从游戏逐帧飞行坐标绘制的侧视及俯视轨迹](回球轨迹.png)

自由飞行最高 1.83 米，终点距网 1.07 米，横向坐标 +1.09 米（以中线为零，近端视角向右为正）。这是按钮测试的固定输入。实际玩家的击球点和挥向会改变结果。[逐帧飞行坐标](</Users/hua/Documents/project/BadmintonRally/data/羽球比赛训练/九场景逐轮验证/20261124-123753-MR4t/自由飞行逐帧坐标.csv>)。

**恢复阶段追加检查。** 本项在触球后 117–800 毫秒窗口内，最大相邻帧握点位移为 2.8 厘米，出现在约 483 毫秒处。可用慢放检视减速、回位与下一拍准备之间的过渡。

## 分镜与实跑差距

分镜中球在身体前侧贴网，前脚承重，随挥很短；游戏后视能看出前场小步，拍面朝向被身体遮去一部分。用场地俯视核对过网横坐标与对侧落点，再决定游戏里的手腕是否需要微调。
