# 挑对角 · 独立单项验收

从低点沿斜线向上带拍；弧高可接近直线挑球。

**这一回法怎样验收**

1. 接触连续。左右手、30/60/120 Hz 六用例均按键触球、回法匹配、预计过网且拍心误差不大于 1 mm。60 Hz 右手的握点在触球帧移距不超过 10 cm。
2. 拍头动作。150 ms 向对角横移至少 12 cm，上升至少 30 cm。
3. 出球线路。右手负侧、落深至少 4.8 m，与直线挑球的弧顶差不超过 0.5 m。
4. 回位连续。60 Hz 右手，触球后 117–600 ms 内拍头的最大相邻帧位移不超过 10 cm。

以上门槛用于本次固定来球的工程筛查。150 ms 取按键后第 9 帧，拍头位置按角色根坐标测量；落深从网面算起。每项计一分，视觉差距另行列出，工程分未评价人体姿态的毫米级准确度。

远端接球队员的移动不能量化球的横角；以相同击球点下两条实跑轨迹交叉检验。 比赛片内观察区间为 1.56–2.92 秒。[真人慢放](</Users/hua/Documents/project/BadmintonRally/data/羽毛球比赛视频/接球动作片段精选/03 网前低于网带/08 挑对角.mp4>) · [逐项分镜与比赛观察](动作.md)

## 第14轮实速独验

对齐正常按键样本的第 119 帧（从 1 计数）。从击前 583 ms 看到击后 600 ms，13、14 轮击后 150 ms 的拍头位移及最终落点按原表精度一致；偏时表现需要另看偏移输入。

球的横向偏移与直线挑球区分清楚，但击前 50 ms 至击后 100 ms 的拍杆被躯干遮住一部分。建议用近持拍侧录像核对绕出身体的拍头路线，并把非持拍臂的过场也纳入对照。

## 游戏中的当前动作与复测录像

挑对角从实际出球方向展开随挥。动画模板的沿球路、竖直、持拍侧横向基准位移分别为 41、+49、+0 厘米，制动用时 200 毫秒，前臂旋转幅度参数为 0.38 弧度。渲染时还会结合实测挥幅、力度、持拍手和可达空间调整。这些数值是游戏参数，录像只能验证最终呈现。

在「网前低点下落球」右手 60 Hz 标准输入下，按键前一帧到触球帧握点移动 7.4 厘米，实际落点距网 5.60 米，横向 -1.61 米，最高 6.10 米。影片保留来球和完整收拍，复盘页可跳到带时间戳的按键帧。
