# 羽毛球动作与第三人称镜头验收标准

适用九种来球场景、27种回法。记录以原片零起始帧号、展示时间戳和画面为依据。项目把玩家按音量键的时刻作为击球时刻。用真人录像复核玩家实际挥向，用参考游戏复核动作是否看得懂，两套证据分别保留。

## 四个参考片段

|---|---|---|
|16.7–17.2 秒，腾空头顶挥拍|人影留地，先离地再出拍，挥后重新接地|蓄力、起跳、触球、落地屈膝、恢复依次可读。通过脚影与场线区分人体上升和镜头上移|
|约 62.0 秒，侧跨抢点|已经击球约 0.2 秒后身体仍处于低位|前脚承重、髋胸一起移向来球，非持拍手保持平衡。等球的晚接动作不能先站直再瞬间下蹲|

## 每项动作如何验收

1. 固定来球、持拍手、按钮时间和挥向，保留正常速度完整录像。保存来球准备、触球前两帧、触球帧、击后两帧、100和250毫秒、回到准备姿势的画面。增加提前65毫秒与延后100毫秒样本，分别报告。
2. 支撑脚、髋、肩、手、拍头逐级检查。低球要看前脚是否先承重、腰部有无突然折转、两臂是否同向僵直；高球要看空手在引拍时指引、主挥前回收；反手底角要看是否转肩以及拍子从身体哪一侧出现。收拍要连续经过减速阶段。
3. 低位承重专项沿用按键时鞋底离地不超过5毫米的项目容差；无法触及的提前按键单列。预计可达的标准时机拍心与球心误差目标1毫米。数值通过还要看录像，记录握点跳变、接触帧及失败的具体动作。
4. 动漫效果以动作轮廓为先。高点击球时网、球、人影必须有空间参照。按键前100到后200毫秒的连续两帧中，头、持拍手或支撑鞋出画即记录构图失败。另查HUD遮挡、球尾与拍弧混淆；检查开启和关闭动态效果。
5. 每轮27项、左右手、30/60/120Hz做球路回归。动效修改应保持按键时刻、回法、碰球位置、过网和落点。每次保留改前和改后录像、测量表及尚未通过项；真实手机宽屏和投电视画幅分别复验。参考视频的节奏为可观测范例，其剪辑、投影和播放速度不足以提供精确骨骼角度或统一动作时长。
