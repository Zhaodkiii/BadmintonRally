# 轻吊

半场高球。本项观察目标为相同机会球分别轻吊与突击，比较回球到网后落地距离。

## 动作流程

```mermaid
flowchart LR
    A["准备 · 保留主动下压的高举拍准备"] --> B["引拍 · 提前到位"] --> C["击球 · 在相近高点向前轻送并控制出射角"] --> D["收拍 · 短随挥结束"]
```

1. **准备**　保留主动下压的高举拍准备。
2. **引拍**　提前到位，肩肘展开，触球前准备减速。
3. **击球**　在相近高点向前轻送并控制出射角。
4. **收拍**　短随挥结束，恢复中场待球位。

## 游戏中的动作与球路

![按键前后连续画面中的四个时刻](游戏阶段.png)

## 分镜与实跑差距

半场轻吊的分镜保留了与点杀接近的上手准备，触球后前臂轻轻送向网前；游戏里副手落下可见，持拍手的减速从背面不易观察。让相同高点分别输出轻吊和点杀，核对触球后早段的拍头下降量与球的落深。
