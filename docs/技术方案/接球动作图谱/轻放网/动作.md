# 轻放网

网前高点机会球。本项观察目标为相同大步上网分别轻托和推远，检查手部用力与脚步解耦。

## 动作流程

```mermaid
flowchart LR
    A["准备 · 靠近网口"] --> B["引拍 · 脚下可以大步"] --> C["击球 · 轻托球底部"] --> D["收拍 · 伸臂停在身前"]
```

1. **准备**　靠近网口，拍头保持可微调。
2. **引拍**　脚下可以大步，持拍手短引。
3. **击球**　轻托球底部，让拍面在网带附近稳定。
4. **收拍**　伸臂停在身前，起身跟住下一拍。

## 分镜与实跑差距

分镜第 3 格拍头轻迎球后向身前收回，游戏轻放的同帧仍须够到与推球相同的触球点。拿两者离拍后短段的握点前送量比对，接触位置相同也应看出轻放制动更早。
