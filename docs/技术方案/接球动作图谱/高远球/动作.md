# 高远球

后场到位高球。本项观察目标为以同一头顶点打吊球和高远，观察弧顶和后场纵深。

## 动作流程

```mermaid
flowchart LR
    A["准备 · 后退到球后"] --> B["引拍 · 非持拍臂辅助平衡"] --> C["击球 · 在头顶前上方伸臂击球"] --> D["收拍 · 跨身随挥"]
```

1. **准备**　后退到球后，侧身举拍。
2. **引拍**　非持拍臂辅助平衡，蹬转带动持拍肩。
3. **击球**　在头顶前上方伸臂击球，向前上送深。
4. **收拍**　跨身随挥，换步重新面网。
