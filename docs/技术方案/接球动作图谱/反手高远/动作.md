# 反手高远

反手底角深球。本项观察目标为固定底角，对比反手与绕头的肩向、起拍侧及落深。

## 动作流程

```mermaid
flowchart LR
    A["准备 · 转身移向反手底角"] --> B["引拍 · 持拍肘领起"] --> C["击球 · 反手侧伸臂向前上发力"] --> D["收拍 · 前臂顺势展开"]
```

1. **准备**　转身移向反手底角，先判断来不来得及绕头。
2. **引拍**　持拍肘领起，球保持在反手侧上方。
3. **击球**　反手侧伸臂向前上发力，给足深度。
4. **收拍**　前臂顺势展开，身体转回面网。

## 游戏中的动作与球路

![按键前后连续画面中的四个时刻](游戏阶段.png)

右手、60 帧/秒的固定来球测试中，玩家目标是**反手高远**，引擎根据输入与击球点给出的回法是**反手高远**。触球前后相邻两帧，手肘移动 3.6 厘米。同一合成输入在基线的握点跳变量为 10.4 厘米，本轮为 3.9 厘米。位移按人物局部坐标计算。

![从游戏逐帧飞行坐标绘制的侧视及俯视轨迹](回球轨迹.png)

自由飞行最高 5.46 米，终点距网 5.76 米，横向坐标 -2.58 米（以中线为零，近端视角向右为正）。这是按钮测试的固定输入。实际玩家的击球点和挥向会改变结果。[逐帧飞行坐标](</Users/hua/Documents/project/BadmintonRally/data/羽球比赛训练/九场景逐轮验证/20261124-123753-MR4t/自由飞行逐帧坐标.csv>)。

**恢复阶段追加检查。** 本项在触球后 117–800 毫秒窗口内，最大相邻帧握点位移为 7.0 厘米，出现在约 417 毫秒处。可用慢放检视减速、回位与下一拍准备之间的过渡。

## 分镜与实跑差距

分镜第 2 格转身露背，让持拍肘先在肩侧折起再向高处伸展；游戏同样能转到反手一侧，但背面镜头难辨握法，真人第 28 段也只可靠地标了高远球。复测时将击球侧、肩转和手背朝向分开记录，回球到后场只能证明球路够深。
