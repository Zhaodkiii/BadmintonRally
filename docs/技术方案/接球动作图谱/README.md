## 数据用途

设计草图定义姿势和动作顺序，真人录像用于复核。游戏实测图来自与 iPhone 共用的 3D 引擎。固定来球使用构造的运动输入，能查出骨架、碰球时刻与球路的问题。真实玩家的握法与操作准确率需要带音量键标记的手机数据。不同机位和帧率的画面不能直接相减作为人体姿态误差。

后续复跑使用项目的 [九场景复测脚本](../../../code/Tools/九场景复测.command)，新结果保存在独立目录。
