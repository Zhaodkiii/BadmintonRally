# 下压突击

半场高球。本项观察目标为与点杀比较出手后前送距离及前段球速。

## 动作流程

```mermaid
flowchart LR
    A["准备 · 向半场空当移动"] --> B["引拍 · 侧身蹬转"] --> C["击球 · 前臂快速往前下穿过球"] --> D["收拍 · 跨身随挥"]
```

1. **准备**　向半场空当移动，准备更充分前送。
2. **引拍**　侧身蹬转，将肘带到高点后方。
3. **击球**　前臂快速往前下穿过球，力量比点杀持续。
4. **收拍**　跨身随挥，落地后稳定重心。

## 游戏中的动作与球路

![按键前后连续画面中的四个时刻](游戏阶段.png)

右手、60 帧/秒的固定来球测试中，玩家目标是**下压突击**，引擎根据输入与击球点给出的回法是**下压突击**。触球前后相邻两帧，手肘移动 4.7 厘米。同一合成输入在基线的握点跳变量为 11.4 厘米，本轮为 4.9 厘米。位移按人物局部坐标计算。

## 分镜与实跑差距

分镜第 3 格前脚压向落点、持拍肩充分前伸，下一格手臂随球下压；游戏在正后方看得到球向前飞，足部换重心不明显。侧视核对出拍后的前送与承重，要求它比同一来球的点杀走得更深。
