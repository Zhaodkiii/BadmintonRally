# 吊球

后场到位高球。本项观察目标为同样腾空也可吊球，核对落深是否由出手控制。

## 动作流程

```mermaid
flowchart LR
    A["准备 · 保留与高远相似的头顶准备"] --> B["引拍 · 侧身举肘"] --> C["击球 · 触球前减力"] --> D["收拍 · 持拍臂轻收；空中处理须先完成落地"]
```

1. **准备**　保留与高远相似的头顶准备。
2. **引拍**　侧身举肘，来得及时可起跳。
3. **击球**　触球前减力，用较短前送送到网后。
4. **收拍**　持拍臂轻收；空中处理须先完成落地。

## 分镜与实跑差距

分镜第 3 格将球员画在网柱旁，便于看清轻送，却容易把这个后场动作误读成网前出手；游戏实际从后场头顶点击出。保留与高远球相近的举拍准备，用击后较短的前送和浅落点表达收力，下一版分镜应画出后场到球网的距离。
