# 正手平抽

身体侧面平快球。本项观察目标为用同目标做反手平抽，观察肩肘和随挥侧别。

## 动作流程

```mermaid
flowchart LR
    A["准备 · 宽站举拍"] --> B["引拍 · 肩微向持拍侧转"] --> C["击球 · 拍面从正手侧迎前横送"] --> D["收拍 · 顺方向过球后收回胸前准备位"]
```

1. **准备**　宽站举拍，给正手身侧留空间。
2. **引拍**　肩微向持拍侧转，肘腕留在身体外侧。
3. **击球**　拍面从正手侧迎前横送，接近平直。
4. **收拍**　顺方向过球后收回胸前准备位。

## 分镜与实跑差距

分镜第 2 格持拍臂在身侧打开，脚距较宽；游戏接触后手臂沿着较平的球路送出，背视下准备阶段不容易读出正手。可以在示范中先展示持拍侧打开，实战里等实际挥拍侧有证据再区分。
