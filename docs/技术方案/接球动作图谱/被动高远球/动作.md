# 被动高远球

平快压底线。本项观察目标为同一受压来球比较平高球和高远球的纵深及滞空时间。

## 动作流程

```mermaid
flowchart LR
    A["准备 · 先到球下"] --> B["引拍 · 侧身后退"] --> C["击球 · 以较高仰角托起球"] --> D["收拍 · 身体在支撑脚上稳住"]
```

1. **准备**　先到球下，保留向上解围空间。
2. **引拍**　侧身后退，击球点允许相对身体偏后。
3. **击球**　以较高仰角托起球，争取回位时间。
4. **收拍**　身体在支撑脚上稳住，再转回中场。

## 分镜与实跑差距

分镜是双脚拉开、身体后仰仍能伸到最高处的处理；游戏这颗压底线的球从体侧较低处击出，只从球的弧线很难看出移动压力。另测到位早晚两档并侧拍，观察最后一步是否被挤短、击球是否落在躯干侧后方，再校对上送的弧高。
