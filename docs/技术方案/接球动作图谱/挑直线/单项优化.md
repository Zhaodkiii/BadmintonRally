# 挑直线 · 独立单项验收

前腿屈膝伸到低点，再沿同侧走廊向上、向前挑起。

**这一回法怎样验收**

1. 接触连续。左右手、30/60/120 Hz 六用例均按键触球、回法匹配、预计过网且拍心误差不大于 1 mm。60 Hz 右手的握点在触球帧移距不超过 10 cm。
2. 拍头动作。150 ms 拍头上升至少 30 cm，向前至少 12 cm，横移不超过 8 cm。
3. 出球线路。落在来球同侧后场，落深至少 4.8 m，弧顶至少 3.8 m。
4. 回位连续。60 Hz 右手，触球后 117–600 ms 内拍头的最大相邻帧位移不超过 10 cm。

以上门槛用于本次固定来球的工程筛查。150 ms 取按键后第 9 帧，拍头位置按角色根坐标测量；落深从网面算起。每项计一分，视觉差距另行列出，工程分未评价人体姿态的毫米级准确度。

真人在侧前方跨步后收回；游戏需表现先低位迎球再上挑，而非先出高弧再抬手。 比赛片内观察区间为 1.56–2.92 秒。[真人慢放](</Users/hua/Documents/project/BadmintonRally/data/羽毛球比赛视频/接球动作片段精选/03 网前低于网带/07 挑直线.mp4>) · [逐项分镜与比赛观察](动作.md)

## 第14轮实速独验

对齐正常按键样本的第 119 帧（从 1 计数）。从击前 583 ms 看到击后 600 ms，13、14 轮击后 150 ms 的拍头位移及最终落点按原表精度一致；偏时表现需要另看偏移输入。

背视从击前 167 ms 的低拍位移到触球时，右脚仍抬高，击后第 14 帧两脚才重新张开。建议加侧视测低球弓步前脚接地及骨盆高度，再判断是否需把支撑提前。
