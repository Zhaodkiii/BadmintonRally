# 挑直线

网前低点下落球。本项观察目标为与挑对角对比过网横坐标，与轻托对比弧高。

## 动作流程

```mermaid
flowchart LR
    A["准备 · 拍头下降"] --> B["引拍 · 屈膝上步"] --> C["击球 · 由下向前上方托起"] --> D["收拍 · 前臂向上送出后回收"]
```

1. **准备**　拍头下降，持拍侧脚对准低点。
2. **引拍**　屈膝上步，在同侧低处让出拍路。
3. **击球**　由下向前上方托起，保持同侧方向。
4. **收拍**　前臂向上送出后回收，支撑腿回蹬。

## 分镜与实跑差距

分镜里前腿压低、触球在膝旁，随后拍头向身前上方延伸；游戏从背后看球升得明显，髋膝的下降较难辨出。复测侧面来球增减横距时的屈膝和前脚着地，同时保持同侧后场的目标线。
