# 推球 · 独立单项验收

从身体前面迎球，用前臂沿场地方向送远，拍头少上扬。

**这一回法怎样验收**

1. 接触连续。左右手、30/60/120 Hz 六用例均按键触球、回法匹配、预计过网且拍心误差不大于 1 mm。60 Hz 右手的握点在触球帧移距不超过 10 cm。
2. 拍头动作。150 ms 前送至少 15 cm，升降绝对值不超过 8 cm。
3. 出球线路。落深 3.0–5.5 m，比同场轻放深至少 1.5 m。
4. 回位连续。60 Hz 右手，触球后 117–600 ms 内拍头的最大相邻帧位移不超过 10 cm。

以上门槛用于本次固定来球的工程筛查。150 ms 取按键后第 9 帧，拍头位置按角色根坐标测量；落深从网面算起。每项计一分，视觉差距另行列出，工程分未评价人体姿态的毫米级准确度。

第 02 段可以确认前送与制动，转播画面里网带与球心的相对高度仍有透视误差。 比赛片内观察区间为 1.56–2.20 秒。[真人慢放](</Users/hua/Documents/project/BadmintonRally/data/羽毛球比赛视频/接球动作片段精选/01 网前高于网带/02 推球.mp4>) · [逐项分镜与比赛观察](动作.md)

## 第14轮实速独验

对齐正常按键样本的第 108 帧（从 1 计数）。从击前 583 ms 看到击后 600 ms，13、14 轮击后 150 ms 的拍头位移及最终落点按原表精度一致；偏时表现需要另看偏移输入。

击后第 14 帧持拍臂仍朝网前伸，确实比同组扑球送得远；背视把拍杆和前臂压在一条线上，看不清肘是否已经锁死。建议加侧视测肘伸幅度，保留推球的前送拍程。

## 游戏中的当前动作与复测录像

推球从实际出球方向展开随挥。动画模板的沿球路、竖直、持拍侧横向基准位移分别为 35、+2、-2 厘米，制动用时 180 毫秒，前臂旋转幅度参数为 0.18 弧度。渲染时还会结合实测挥幅、力度、持拍手和可达空间调整。这些数值是游戏参数，录像只能验证最终呈现。

在「网前高点机会球」右手 60 Hz 标准输入下，按键前一帧到触球帧握点移动 2.3 厘米，实际落点距网 3.61 米，横向 +1.16 米，最高 1.90 米。影片保留来球和完整收拍，复盘页可跳到带时间戳的按键帧。
