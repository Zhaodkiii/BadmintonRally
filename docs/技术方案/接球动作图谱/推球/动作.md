# 推球

网前高点机会球。本项观察目标为与扑球比较出球仰角，与轻放网比较落地纵深。

## 动作流程

```mermaid
flowchart LR
    A["准备 · 举拍封住网口"] --> B["引拍 · 侧身上步"] --> C["击球 · 顺空当持续前送"] --> D["收拍 · 前臂再送一段后制动"]
```

1. **准备**　举拍封住网口，留出向前伸臂的空间。
2. **引拍**　侧身上步，拍面迎住来球。
3. **击球**　顺空当持续前送，按键时手仍向前。
4. **收拍**　前臂再送一段后制动，回到拦网位。

## 游戏中的动作与球路

![按键前后连续画面中的四个时刻](游戏阶段.png)

右手、60 帧/秒的固定来球测试中，玩家目标是**推球**，引擎根据输入与击球点给出的回法是**推球**。触球前后相邻两帧，手肘移动 2.3 厘米。同一合成输入在基线的握点跳变量为 8.9 厘米，本轮为 2.3 厘米。位移按人物局部坐标计算。

## 分镜与实跑差距

分镜触球时前臂沿球路向前伸，游戏同一高点也有前送，背面画面却容易与扑球的抬臂混在一起。并排看击后 150 毫秒的前送和高度变化，保留推球较平的拍头路线。
