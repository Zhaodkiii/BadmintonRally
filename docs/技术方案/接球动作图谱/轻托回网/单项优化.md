# 轻托回网 · 独立单项验收

用拍面在低点托起，略向前送后制动，拍头不要像挑后场那样大幅抬高。

**这一回法怎样验收**

1. 接触连续。左右手、30/60/120 Hz 六用例均按键触球、回法匹配、预计过网且拍心误差不大于 1 mm。60 Hz 右手的握点在触球帧移距不超过 10 cm。
2. 拍头动作。150 ms 上升 4–20 cm，前送 2–12 cm。
3. 出球线路。落深 0.4–1.6 m，弧顶比同场挑直线低至少 1.5 m。
4. 回位连续。60 Hz 右手，触球后 117–600 ms 内拍头的最大相邻帧位移不超过 10 cm。

以上门槛用于本次固定来球的工程筛查。150 ms 取按键后第 9 帧，拍头位置按角色根坐标测量；落深从网面算起。每项计一分，视觉差距另行列出，工程分未评价人体姿态的毫米级准确度。

真人示范在急赶低球时很深地跨出，游戏应当允许大步救球但小幅托拍。 比赛片内观察区间为 1.56–2.52 秒。[真人慢放](</Users/hua/Documents/project/BadmintonRally/data/羽毛球比赛视频/接球动作片段精选/03 网前低于网带/09 轻托回网.mp4>) · [逐项分镜与比赛观察](动作.md)

## 第14轮实速独验

对齐正常按键样本的第 119 帧（从 1 计数）。从击前 583 ms 看到击后 600 ms，13、14 轮击后 150 ms 的拍头位移及最终落点按原表精度一致；偏时表现需要另看偏移输入。

击后约 100 ms 能看到球较浅地越网；持拍手靠近肩部轮廓，原地回收中较难看出指腕卸力。建议侧视对比同点轻托与挑直线的拍面仰角，保留目前较短的上送段。

## 游戏中的当前动作与复测录像

轻托回网从实际出球方向展开随挥。动画模板的沿球路、竖直、持拍侧横向基准位移分别为 9、+14、+0 厘米，制动用时 160 毫秒，前臂旋转幅度参数为 0.12 弧度。渲染时还会结合实测挥幅、力度、持拍手和可达空间调整。这些数值是游戏参数，录像只能验证最终呈现。

在「网前低点下落球」右手 60 Hz 标准输入下，按键前一帧到触球帧握点移动 7.4 厘米，实际落点距网 1.08 米，横向 +1.41 米，最高 1.97 米。影片保留来球和完整收拍，复盘页可跳到带时间戳的按键帧。
