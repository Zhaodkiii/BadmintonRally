# 动作分镜生成记录

生成工具为内置 ImageGen，单项单独生成。各图按右手运动员绘制。横向四格依次表示准备、引拍、击球、收拍；镜头采用能看清持拍臂的四分之三侧视，浅色纸面、墨线人物、青色球拍、橙色羽球。颜色与角度用于阅读设计。球路和动作相位以逐拍数据与比赛复核为准。
