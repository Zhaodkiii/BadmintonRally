# 平高球单项优化与独立验收

被快球压向底线时打低弧深球，早晚都有相应的触球高度与前距。

## 本项验收条件

落深至少4.5米，弧顶比同球的被动高远低至少1米；±65毫秒时机用例全部触球并过网。 这些数值是本轮为固定喂球设定的工程对照值。站位、握法与触球高度改变时，须另外验证。三档帧率和双手共六次均应确认击球，拍面距球心不超过1毫米。球路与姿势分别判定。

## 比赛参照与基线差距

基线的出球已经够深；触球帧拍面和躯干有遮挡，受压和主动到位的差别不好读。 [真人阶段与片段出处](动作.md)

## 当前判定与复测重点

按早65、正常、晚65毫秒分别复核肘、腕、拍面和髋部制动。

## 第一次优化的独立观察

球穿向后场时手臂低于被动高远球，约300毫秒手肘已向侧方收回。触球帧仍有前臂与躯干视觉重叠。 安排早、中、晚各一组侧前机位，检查身体后方被压时的让拍空间。

## 第二次优化的独立观察

击后150毫秒仍偏向前送，300毫秒已恢复到较低持拍位；与被动高远上送分开。早晚按键测试中仍需保留球在身体前后的实际距离，才能解释极迟下网。

**扩展时机检查。** 将同一动作扩展为提前65毫秒、预计时刻、延后65毫秒，双手各在30、60、120帧下测试。18例中有 18 例拍球误差不超过1毫米；最差误差 0.0 厘米。另加延后150与200毫秒共12例，8例过网。
