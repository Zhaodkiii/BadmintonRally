# Nintendo Switch Sports 羽毛球体验拆解

研究范围为 2022 年 Nintendo Switch 原版的羽毛球项目。交付对象为独立验收委员会。下面的“本作测试”是 BadmintonRally 的对标提案；委员会保留独立解释、提出反例和退回的权力。资料覆盖可观察体验和公开的设计决策。闭源的完整动画树、碰撞几何、网络补偿和传感器模型参数仍未知。

## 一分球如何成立

准备和发球建立本拍主动方 → 对方来球给出方向、高度与剩余时间 → 玩家选择迎球时刻、方向及回法 → 角色以符合距离的姿势完成或错过挥拍 → 球路让双方看懂质量 → 对手和自己各自回位 → 下一拍或得分。拆解时至少看到下一拍准备；只看球离拍无法评价一颗挑球是否真的给玩家换来回位时间。

| 层次 | 参考作品中值得观察的因果关系 | 在本作怎样证伪 |
|---|---|---|
| 入门与输入教学 | 基本挥动对应直观球路，熟悉后才加入左右调动和吊球。开发者报告过，新玩家会困惑于用早晚决定左右。[官方教学](https://www.nintendo.com/jp/ichikara/as8sa/02_en.html) · [开发者访谈第二部分](https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-5-nintendo-switch-sports-part-2/) | 首次玩家口述想打方向，Mac 先隐藏实际落点；同姿同刻朝左、中央、右各打，再单独只改按键时刻。若变早晚比挥向更能改变左右，查映射。 |
| 发球与得分 | 发球开启回合，落在对方场内、回球出界产生明确结果；参考入门教程介绍先得五分。本作采用自己的比赛计分与发球区规则。[官方入门](https://www.nintendo.com/jp/ichikara/as8sa/02_en.html) | 从 0:0 连续打到结算，核对Mac 开发采集端归档的球次、iPhone 比分、站位和发球权；分别打短发与偷后场，记录对角落点。Mac 关闭时再打一局。 |
| 战术与球路 | 上手下压用于进攻，下手挑高能争取恢复时间，吊到网前可打断快速相持；横向改变落点能调动对手。[官方动作页](https://www.nintendo.com/jp/switch/as8sa/badminton/index.html) · [官方技巧](https://www.nintendo.com/en-za/News/2023/April/Nintendo-Switch-Sports-Tips-and-Tricks-2380312.html) | 同一后场高球分别吊、挑高回深和扣；比较出射角、网前净空、飞行时间、落深及对手抵达时间。用同一力量只改挥向，再看落点横向排序。 |
| 接球时机与困难球 | 官方教学提及距离过远时可能失衡，质量差的晃球给对手机会。参考作品的强化扣杀属于额外设计。[官方教学](https://www.nintendo.com/jp/ichikara/as8sa/02_en.html) | 固定同球同刻只改起始距离：站稳挡、跨步接、够不到。再固定距离只改早晚。观察失败是否有身体动作和可理解的后果，记录挥空、擦到下网或形成机会球。 |
| 持拍角色与动作库 | 手臂与身体相连后，要处理挥拍角度和前、斜、后移动，也要区分行走和跑动。任天堂谈到约 30 到超过 650 个动作，口径为两代角色制作的整体比较，不能记为羽毛球专属动作数。[角色制作访谈](https://www.nintendo.com/en-gb/News/2022/May/Ask-the-Developer-Vol-5-Nintendo-Switch-Sports-2215553.html) | 把九种来球场景作为行，按到位早晚、正反手、近远身、移动中或已站稳、恢复方向逐格抽查。先让最常见格子连贯，跨区不足时换步法，限制肘肩伸展。 |
| 预判、移动与恢复 | 参考片能观察起跳前准备、侧向救球和低位回位的不同姿势；镜头无法直接揭示是否采用状态机、动作匹配、IK 或根运动。[录像核验](../独立验收/01-参考分析/任务/V001-参考片核验.md) | 无球、无拖尾先盲看：哪只手、哪只脚承重、是截高点还是赶低点？再放回球，检查最后一步到位后有无追着球滑、支撑脚有无漂移。 |
| 触拍、飞行与视角 | 通过人体、网带和球相对大小读出纵深；离拍后的轨迹和下一拍机会互相印证。注意教程的剪辑、慢放和字幕可能改变对节奏的感知。[参考联系表](../独立验收/01-参考分析/证据/V001-参考片动作联系表.jpg) | 正式机位正常速度定位一次触拍，再用侧面几何核验。暂时关轨迹，若人物、球、球网在同一平面挤成一点，分查镜头、站位、拍面和时钟；采集真实出球方向并与屏幕投影对照。 |
| 音效、效果与环境 | 制作团队考虑体感反馈声、环境声和场馆所传达的运动氛围。公开视频听到的合成声轨无法单独给出输入延迟或触感强度。[声音与场景访谈](https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-5-nintendo-switch-sports-part-3/) | 有声、静音及关闭拖尾分别验一拍。击中时球变向与击球声关联，挥空时不得响成功反馈。用同步外部录像量真实投屏延迟，在日志中另存系统确认按键的时刻。 |
| 输入识别与响应预算 | 开发者披露过采集多人左右挥动样本、尝试深度学习以及“多等样本”与响应速度之间的取舍。访谈没有披露可复用的完整模型、采样窗与设备阈值。[体感研发访谈](https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-5-nintendo-switch-sports-part-2/) | 用音量键作为击球时刻。在线仅使用当时可用的挥动数据，事后录像可用于标注。分别报左右手的方向误差、轻中重落点分布、第二拍漏接、从按键到画面的延迟。 |
| 对局节奏和难度 | 正常回球给对手选择，过早抢击可能被动，挑深增加回位时间。场馆、观众和色彩可借鉴其信息层次。[官方教学](https://www.nintendo.com/jp/ichikara/as8sa/02_en.html) · [官方首发演示入口](https://play.nintendo.com/media/videos/nintendo-switch-sports-launch-trailer/) | 在相同速度来球下分别挡网和挑深。观察对手拦截位置、个人恢复到下一次可行动的时间，以及角色跑速是否足以解释抵达时刻。关闭辅助标记后再辨认落点。 |

## 同一颗来球，为什么能产生不同体验

| 参考中的情况 | 球飞出去以后还要看什么 | 本作的对应实验 |
|---|---|---|
| 上手进攻 | 起速快、给防守方的反应时间缩短。强弱还要结合实际击球高度和回球质量看。 | 固定高点交替快压、减力轻吊。对比过网高度、首次落地位置及防守可用时间。 |
| 下手挑高 | 高弧线买到时间，击球者有机会结束救球姿势、回到准备位。 | 同一低球先轻托再挑深。逐球记录最高点、飞行时长及角色回位是否赶在下一拍前。 |
| 吊网前 | 落点短迫使后方对手向前。若只改弧线颜色、对手仍站在原地，战术差异实际上没有生效。 | 同一后场来球尝试吊、打深。比较前后移动距离和对手触球点。 |
| 左右调动 | 连续打向同侧与突然变线，区别应当体现在下一步的方向和身体转向。 | 保持来球、按键与力度近似，交替直线、对角，不给接球角色瞬移或自动吸球。 |
| 仓促回球与机会球 | 上一拍的质量会改变下一拍机会。参考游戏另有晃球及更强扣杀表现。 | 记录上一拍失误或被迫挑高、下一拍可进攻的高度和能否下压，不强制复刻颜色或数值增益。 |
| 太远、失衡或挥空 | 失去平衡和恢复需要时间，下一拍能否赶到才赋予失败代价。 | 同一颗球按键时站位差半步与差一整步；看能否补步、是否实际触球、何时恢复可操作。 |

参考动作定义来自[任天堂羽毛球教学](https://www.nintendo.com/jp/ichikara/as8sa/02_en.html)。表中的量测、失败代价与本作九场景映射为项目实验设计。测轨迹时并列保存世界空间球心、拍床位置与最终镜头画面，才能区分物理上向前飞、画面投影看似向侧面飞的情况。

## 给验收员的独立理解题

1. 同样在低位接球，为什么近身挡和远身救不能只是给同一个挥拍加速？请引用两个原片时间码，用脚、髋、拍床和下一步恢复解释。
2. 玩家有意回左边但晚按了键。哪些结果仍合理，什么证据能证明确实把横向挥动读反？请给一条能推翻自己结论的对照实验。
3. 角色已经出手，屏幕上球在手背旁经过。如何用正侧两机位、拍床局部坐标和音效事件，区分投影重叠、实际漏接和提前播放反馈？
4. 如果一段扣杀靠闪光才看得懂，哪些条件应退回视觉，哪些应交玩法检查？不要用手柄输入的不可见部分为画面作证。
5. 参考游戏的 ZR、五分制和强化扣杀与本作的音量键、比赛计分、连续力度有哪些不同？验收应保留哪种玩家体验，哪些属于产品选择？

## 独立交付与结论边界

参考分析员负责原片证据与动画设计出处，玩法验收员负责规则和受控用例，视觉验收员负责无标签可读性与反例。每位直接阅读原始资料并在自己的任务目录作答。验收主任检查不同岗位是否能独立复述同一机制、证据冲突如何裁决、哪些陈述仍属猜测，然后决定这份研究能否用作以后提测的判据。研究验收与游戏版本验收分别留档。教学视频仅供内部研究；可公开访问的链接、原片秒数和少量对照图足够定位。
