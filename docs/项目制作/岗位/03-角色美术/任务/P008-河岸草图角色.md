# P008 河岸球馆比赛角色

接单对象为正式比赛近方及远方首发角色。以河岸球馆草图的准备姿势、服装配色、低对比木炭线和鞋袜作为美术依据。交付为比赛角色网格、姿态修改及左右手三帧测试。

## 正式角色交付

近方栗色马尾加珊瑚色双耳发结，缩小头部轮廓，暖珊瑚上衣改用同色侧片及下摆斜褶，青绿短裤配护腕、浅袜和生胶色鞋底。远方采用草图的砂色球衣和炭灰短裤。球拍改为赭金拍框与暖白拍线。角色表面的暗面、转折与轮廓采用连续色阶。准备时髋下沉、胸前倾、双脚分开并错开，持拍侧打开；主挥仍由原有接触求解器控制。

[首发双方同机位近景，左旧右新](P008-证据/双方同机位对比.jpg) 为正式比赛 SceneKit 管线在 Mac 离屏渲染的第 18 帧。美术对照固定使用 P007 机位、背景和同一输入，两格均从相同画幅以原始像素裁切。角色在动态视角中的实际占屏率另交场景机位及独立验收复核。

Swift 编译通过。左右手共 496 帧的近远端球衣纵向比例均为 1，近方腿段长度最大误差 0.00000015 米。三帧触达八个场景断言通过，输出 24 帧。[触达数据](P008-证据/触达回归.csv)
