# 角色美术怎样让玩家读懂一拍

2026-11-25，03 角色美术执笔，P001 提交版。

## 玩家眼里的这一拍

对方站在后场，低球落在我方右前。玩家先从来球相对网带的位置读出下降趋势，再看持拍手和前脚离拦截点有多远。够得着时，按键前用短而轻的挥动选择挡网，在球进入有效拍床时按音量键。落点足够短，对手就要向前赶；对手未能合法回球，这一分才结束。若自己正跨步失衡，另一种合理选择是挑深，用更长的飞行时间收腿站稳。只有体态、出球和下一步能连起来，玩家才知道自己的选择起了什么作用。

我的交付是让背面角色的持拍侧、支撑腿和伸展极限清楚可见。马尾能帮助认出角色，甩到持拍侧时也可能遮住小臂；远身低接能靠前膝屈曲、后腿伸展及两腿间的空隙传达重心，短挡则要保留肘、手、拍头之间的轮廓。服装褶皱和发束细节要在实际球场背景、正常播放尺寸下复查。

**能推翻我的判断的反例。** 固定同一颗低球，只改变站距，打乱 A 近身与 B 远半步的无球、无拖尾片段。若观察者要看角色旁的标签才能指出哪段跨步，剪影就未达到目标。若 C 超距挥空在背面看似命中，先看同帧侧机位和有效拍床位置；侧面显示拍床够不到球、背面却被马尾遮挡时，我要返修遮挡。若两机位上球都提前变向，则交动画程序和玩法程序追查时序。[R001 判据](../../../独立验收/00-验收主任/任务/R001-团队理解验收.md) · [V002 裁决](../../../独立验收/00-验收主任/任务/V002-裁决.md)
