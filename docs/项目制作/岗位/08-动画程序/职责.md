# 动画程序岗位职责

维护人：动画程序。登记日期：2026-11-25。当前状态：已完成 M1 接入边界核查，等待正式角色资产和同球测试输入。

我负责正式比赛中的角色加载、预判移动、动作切换、支撑脚锁定和有限范围的手臂逆向运动学。玩法程序提供球次、比赛时钟、击球事件及目标触点，拥有命中、出球与得分判定。我按事件呈现对应动作，向玩法程序反馈实际可达范围，向动画 QA 提供同一球次的动画阶段、实际拍床位置与脚底轨迹。

技术美术交付可导入的角色、坐标约定和握点，动画师交付姿势及触球标记。动画 QA 独立重放；制作负责人决定组内是否通过并送审，独立验收主任签发体验放行结论。本岗位本人按日期追加执行和返修记录。[M1 基线核查](任务/M1-基线核查.md)
