# P005 · 固定拍杆时，握持手不再隔帧翻面

2026-11-25，动画程序本人实施。用 Mac 的正式比赛角色重放固定动作后，定位到握持手网格在远身低球和反手准备中突然绕柄转到另一侧。网前低点下落球的远位起步样本最清楚：F98→99 拍杆方向余弦约为 1，拇指根却一帧移动了 60.54 毫米（已扣除握点平移），手指绕杆转过 142.66°。相邻帧图可以沿黑色拍柄对照拇指在哪一侧。[修前／修后同帧握持手图](P005-握柄翻面修前修后.jpg)

## 实施

原先从前臂与场地方向的叉乘决定指节方向。当两方向接近平行时，即使拍杆近乎不动，该参考方向也会翻到另一面。现在由 PlayerHands 将上一帧的指节方向随拍杆转到本帧，再向目标握姿逐步旋转。连续时按游戏步长限制绕杆调整速度为每秒一圈（60 Hz 每帧最多 6°），拍柄的平移和方向仍由原 IK 驱动；切手、跳时等不连续情况重新取当帧朝向。持拍手的指节和腕到掌的连接段使用同一解。[SpatialCourt.swift](../../../../../code/Clients/iOS/Art/SpatialCourt.swift)

与 07 的分工：07 设计反手命中与挥空的随挥路径及平衡臂准备，本人合入两次动作补丁；本人负责握持手朝向和出球几何回归。终版 SpatialCourt.swift SHA-256 为 195be49cd5330a3afda5c017fed16c85b85624f3240dcac41dae65d50b99e7ab。

## 保留问题与交接

网前远位 F98→99 的终版掌节点仍有 **299.73 毫米世界位移**。本次证实并修正了握持手相对于拍柄的翻面；要判断这次整臂平移是否由目标切换、球员根节点移动或 IK 限制造成，还需独立比对腕、肩与脚位。另未在此样本中定量证明肩穿躯干或肘网格塌陷。交 10 动画 QA 独立重放 F77→78、F95→96、F98→99；负责人负责指定模拟器的正式录像与放行。本岗位未使用真机。
