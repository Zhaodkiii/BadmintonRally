# P006 · 正式比赛镜头正对球网

2026-11-25，动画程序本人实施并在 Mac 离线复测。原机位在球员背后的侧方，每帧回瞄球场中央。即便球网两根柱子等高，镜头转向仍使横线两端在画面上出现高差。我保留角色跟拍所需的位置变化，固定相机向世界 −Z 轴看、朝下俯视 20°。脚位只触发横向和纵向平滑平移；左右手使用镜像的小幅侧移，动作和回球不触发偏航、滚转或变焦。减动模式保持固定位置。[比赛相机实现](../../../../../code/Clients/iOS/Art/SpatialCourt.swift)

## 第二轮：远端球员在对手挥拍前的接发准备

我用双方新版角色、正式比赛动作代码复放固定反手平抽。旧版 F80–101 远端头部局部高度保持 1.586 米，两鞋中心间距保持 0.400 米，F87–101 拍框相对人物根节点的位置恒定。远端球员在此前的确有随挥，但随挥后直接停在架拍姿势。近端 F87 的握点在头心右 9.52 像素、下 2.75 像素（左手镜像），二维轮廓重叠疑点仍保留，无法单凭此判断手部穿入头部。

本轮修复远端球员：来球朝近端飞时，远端按球路进度屈膝、打开平衡臂、把拍面送至身前；对方出球后平滑卸载，进入已有的拦截动作。远端发球时从腰前备拍，接发时先降低重心。相邻动作通过同一比赛时钟衔接。双脚支撑点保留原位。
