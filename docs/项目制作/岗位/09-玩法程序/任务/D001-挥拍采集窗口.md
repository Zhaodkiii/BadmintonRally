# D001 挥拍采集窗口
2026-11-25 接单，进行中。依赖原始事件、采样时钟与摄像帧索引。目标是向制作负责人交付可复现的逐挥拍相对视频时间范围与证据来源。

完成。实现见 `code/Tools/swing_windows.py`。100 个比赛目录逐批读取并核对场次及序号，91 个目录共得到 3264 个候选中心，其中 1098 个来自音量键，911 个来自 impact，916 个来自起拍预览，47 个来自判断记录，292 个来自仅有 IMU 证据的动作。57 份训练采集中 56 份有完整动作提示窗口，在这些窗口中检测到 93 处角速度活动；另一份缺少动作窗口。

事件中心保留手机单调时钟。训练相机由探针拟合并换算，比赛相机和游戏录屏由各段专属帧索引映射。自动检测仍可能把收手、走动识别成挥动，未逐条人工标注。原始事件、样本、时钟表和帧表留作复查。交接对象为制作负责人，按具体录像覆盖范围剪辑并校验。
