## 判定代码与测量边界

1. 正式比赛在 ClubView.swift 第 747 行调用 game.swing，传入 confirmedByButton。夹具走同一方法，输入由合成器产生。[比赛按键入口](../../../../../code/Clients/iOS/UI/ClubView.swift) · [扫描程序](../../../../../code/Tests/Checks/MiddleContactTiming.swift)
2. Rally.swift 第 594–628 行使用当前游戏时刻，核对落地、过半场、高度及球员与球的水平距离。水平距离超过 2.40 米会被拒绝；确认按键路径跳过另外两个用于普通挥拍的检查。第 701 行从该时刻的球位置生成回球。此判断未查询渲染场景的拍床几何，四行的零衔接误差可由这种起点构造解释。[Rally.swing](../../../../../code/Clients/iOS/Game/Rally.swift)
3. 夹具先执行 swing 再更新场景；SpatialCourt.swift 第 1159 行计算拍尖世界坐标与触球世界坐标的欧氏距离。当前证据能复现距离突增。没有有效拍床的边界、姿态和相邻帧扫过区域，就不能认定已挥空或已接触。[距离实现](../../../../../code/Clients/iOS/Art/SpatialCourt.swift)

## 从项目根目录复跑

```sh
t=$(mktemp -d)
swiftc code/Clients/iOS/Game/Rally.swift code/Clients/iOS/Art/ReturnMotion.swift code/Clients/iOS/Art/SpatialCourt.swift code/Tests/Checks/MiddleContactTiming.swift -o "$t/middle"
"$t/middle" > "$t/middle.csv"
sed -n '/^```csv$/,/^```$/p' docs/独立验收/02-玩法验收/任务/V002-夹具复验.md | sed '1d;$d' > "$t/original.csv"
cmp "$t/original.csv" "$t/middle.csv"
awk -F, '$1=="反手平抽" && ($3==-100 || $3==-50)' "$t/middle.csv"
```

本次定位限于 macOS 60 Hz 合成扫描。偏移相对于预测拦截点，并按游戏帧采样。未测实体键延迟、正式人物的实际拍床或背侧双机位。下一步把四个球次交动画程序提取球心、有效拍床和前后一帧，交独立玩法与视觉验收员复核离拍先后。若实际拍床未及球就已出球，按对应球次返工。正式比赛仍待复验。
