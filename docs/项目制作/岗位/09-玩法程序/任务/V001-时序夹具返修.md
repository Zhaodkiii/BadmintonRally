## 复跑与证据

在项目 code 目录用 zsh 执行。CSV 首行为列名，其余为完整样本。

```sh
t=$(mktemp -d)
swiftc Clients/iOS/Game/Rally.swift Clients/iOS/Art/{ReturnMotion,SpatialCourt}.swift Tests/Checks/MiddleContactTiming.swift -o "$t/middle"
env NSUnbufferedIO=YES "$t/middle" > "$t/results.csv"
wc -l "$t/results.csv"
```

本次进程退出 0，CSV 共 91 行。按回法、左右手、偏移毫秒去重得到 90 组，覆盖 9 种回法 × 2 只持拍手 × 5 档偏移（−100、−50、0、+50、+100 毫秒）。90/90 完成，程序内剩余断言失败 0 项。
