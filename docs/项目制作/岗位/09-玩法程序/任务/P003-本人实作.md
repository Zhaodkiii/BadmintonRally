# P003 · 让来球经过拍面后才变向

2026-11-25，09 玩法程序实施并复跑，08 动画程序提供候选姿势，10 动画 QA 独立量测。当前状态为制作线修复，正式比赛真机放行待独立委员会裁决。

## 复现、根因与生产改动

固定中场平抽，按键前挥向、力度、来球一致。本人把站位换算成世界米，左右手在提前 100 毫秒时球距脚中心约 1.668 米，提前 50 毫秒时约 1.182 米。旧规则只需通过水平距离 2.40 米等检查便提交出球。QA 读实际 SceneKit 节点，前一球候选触球帧的球托与拍床内缘还相隔 113.71 毫米，后一球的球托已接触拍床。前一球应当继续飞行。[旧基线](P002-本人实作.md) · [QA 三帧数据](../../10-动画QA/任务/P003-证据/修前.csv)

我改了两个生产入口。每场比赛创建自己的 CourtScene，实际显示与实体按键校验使用同一实例。Rally 在副本上用原规则选择回法、求当刻候选出球和动作，再调用 08 的拍床几何检查。几何接触才整体提交副本；挥空时真实局面仅记录按键时间、挥拍和“拍面未触球”，原来球、回球数、连击和成功反馈继续保留。发球及原有提前、落地、超距等拒绝分支沿用原逻辑。[ClubView](../../../../../code/Clients/iOS/UI/ClubView.swift) · [Rally](../../../../../code/Clients/iOS/Game/Rally.swift) · [拍床与球托几何](../../../../../code/Clients/iOS/Art/SpatialCourt.swift)

62 项扩展验证使用 CourtMotionLab 的 trials、TrialRunner 和正式接球回调，在项目 code 目录、上面同一 shell 中执行。每组最多推进 280 帧，发球沿用原入口。

```sh
python3 - "$t/nine.swift" <<'PY'
from pathlib import Path
import sys
s = Path("Tools/CourtMotionLab.swift").read_text()
i = s.index("private final class TrialRunner")
s = s[:s.index("\n}", i) + 2]
s = s.replace("confirmedByButton:true) == .accepted",
              "confirmedByButton:true,validateContact:{ self.court.canContact($0,left:$0.leftHanded) }) == .accepted")
s = s.replace("reduced:false", 'reduced:CommandLine.arguments.contains("--reduced")')
s += """
@main enum Scan {
  static func main() {
    for trial in trials {
      for left in [false,true] {
        let r = TrialRunner(trial,left:left,contactOffset:0)
        for _ in 0..<280 { r.step(); if r.attempted { break } }
        print(trial.name, left, r.hitTime != nil ? "OK" : "MISS")
      }
    }
  }
}
"""
Path(sys.argv[1]).write_text(s)
PY
swiftc Clients/iOS/Game/Rally.swift Clients/iOS/Art/{ReturnMotion,SpatialCourt}.swift "$t/nine.swift" -o "$t/nine"
"$t/nine" > "$t/normal.txt"
"$t/nine" --reduced > "$t/reduced.txt"
diff "$t/normal.txt" "$t/reduced.txt"
awk '/ OK$/{ok++} END{print ok, "通过 /", NR, "项"}' "$t/normal.txt"
```

本岗量测采用合成输入和 60 Hz 模拟时钟。手机实体音量键的真实延迟、投屏延迟及正式首页一局的录像另由设备与独立验收岗位记录。候选姿势按键时刻的离散几何检测未覆盖两帧之间擦过球托的连续碰撞案例。
