## 入口与输入

启动参数 `-p006Singles` 仅在 Debug iOS 模拟器启用。程序先显示首页和比赛设置，再调用正常的单打开始方法。设置一局、右手、标准对手，每次回合按 60 Hz 游戏时钟推进。可复现性的两个条件是相同的 AI 随机种子 6006 和每个游戏步更新一次正式球场姿势。一般玩家继续使用原来的系统随机源。

## 独验如何录一场

仅在项目约定的 iPhone 18 Pro、iOS 27.2 模拟器运行。从项目根目录执行。首次须有该模拟器的正常启动状态。下面的编译只生成调试包，安装与启动命令显式指定唯一 UDID。

```sh
udid=89B4EB3F-3B23-4F9F-AA91-5D3AC77016A8
bundle=com.daokaihua.badmintonrally
run_dir=$(mktemp -d)
xcodebuild -project code/BadmintonRally.xcodeproj -scheme BadmintonRally -configuration Debug -destination 'generic/platform=iOS Simulator' -derivedDataPath "$run_dir/build" CODE_SIGNING_ALLOWED=NO build
xcrun simctl install "$udid" "$run_dir/build/Build/Products/Debug-iphonesimulator/BadmintonRally.app"
container=$(xcrun simctl get_app_container "$udid" "$bundle" data)
ledger="$container/Documents/P006-单打.tsv"
touch "$run_dir/begin"
xcrun simctl io "$udid" recordVideo "$run_dir/正式单打.mp4" > "$run_dir/video.log" 2>&1 &
recorder=$!
sleep 2
xcrun simctl launch --terminate-running-process "$udid" "$bundle" -p006Singles
```

记录文件每次启动都会重建。独验先确认本次文件已更新，有 start 和 0∶0，然后跟踪每次 point 的比分和发球归属。finished 表示程序已将比赛切到结算页；停录前多留两秒。若满十五分钟仍未结束，应保留当时的录像和最后事件以定位卡点。

```sh
for i in {1..900}; do
  if [[ "$ledger" -nt "$run_dir/begin" ]] && awk -F '\t' '$1=="finished" {ok=1} END{exit !ok}' "$ledger"; then
    break
  fi
  sleep 1
done
sleep 2
kill -INT "$recorder"
wait "$recorder"
cp "$ledger" "$run_dir/正式单打.tsv"
tail -3 "$run_dir/正式单打.tsv"
```

验收核对每条 point 只增一分，下一发归本分赢家；finished 的比分符合 21 分、20 平后两分优势或 30 分封顶。还应在录像逐分对表，并确认片尾出现相同比分与成功回球数。输入来自模拟注入，实体按键与真实 IMU 延迟属于模拟器无法验证项。
