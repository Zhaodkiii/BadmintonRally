# 玩法程序怎样让玩家赢下一拍

晚风球社的目标，是让玩家从 iPhone 首页进场，自己打完一场能投屏的单打。低球飞到身前时，我希望玩家先看它相对网带的高度，再决定是减力短挡逼对手上前，还是挑向底线给自己多留一步回位时间。音量键确定出手时刻，键前挥动给出方向、角度和力度。上一拍若迫使对手勉强挑高，下一拍才有下压的机会。一局结束时，最后一次落点或失误应该能解释比分和发球权的变化。[总纲](../../工程项目总纲.md) · [参考研究](../../../参考研究/SwitchSports羽毛球拆解.md) · [R001 理解裁决](../../../独立验收/00-验收主任/任务/R001-团队理解验收.md)

## 一次输入怎样产生可以查证的后果

我负责把按键和键前的传感器样本换算到回合时钟，在同一时刻取球的位置和选手的可达状态，再记录拒绝原因或出球起点、速度、过网、落地与结算。动画程序提供这一帧拍床的实际位置。如果球在有效拍床接触前变向，判定就要退回；如果在相同来球、站位、时刻和力度下反转横挥，左右落点仍总在同侧，也能推翻方向映射正确的判断。对同一来球，较深的挑球能否给我多留回位时间，还要量到对手下一次触球。

## 已有作品与证据缺口
