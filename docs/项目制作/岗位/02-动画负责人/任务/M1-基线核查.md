# M1 近身短挡与远身救球基线核查

2026-11-25 · 任务号 M1-基线核查 · 执行人：动画负责人 · 状态：待验收

## 目标与通过条件

我负责确认现有素材足以交代哪些动作，以及正式比赛还要拍什么。正式视效签字需要在相同来球、相同比赛机位和播放速度下，分别从准备看到回位。隐去标签时，近身可读出双脚站稳、前臂短送和回髋；远身可读出右脚先跨、降髋和膝外伸拍。逐帧核对球头进入拍面与出球转折，检查回位是否滑脚。

## 已做与证据

1. 我查阅 R34 最终视觉及技术记录。近身短挡首评被读成准备姿势，返修版在 300 × 200 像素下能读出短送和回收。远身救球调整机位后可看见右膝外的手和拍头。[R34 独立总结](../../../../../assets/美术/女球员独立制作/R34动作样片/验收/独立总结.md)
2. 两段低球均为单循环。记录中的 151 个球头位置逐帧一致，均在 0.575 秒于框内触球，球头中心距拍面 2.398 毫米。准备至接触，近、远身右鞋位移分别为 0 和 1.088 米。该组数字取自原场景复测档案。[R34 技术验收](../../../../../assets/美术/女球员独立制作/R34动作样片/验收/技术验收.md)
3. 我从比赛页面定位到 ClubView.swift 第 79 行调用 SpatialCourt，再从 PlayerPreview.swift 第 39 行定位到动作预览加载的场景。复查时可在工程根目录执行下方只读检索。[比赛入口](../../../../../code/Clients/iOS/UI/ClubView.swift) · [预览入口](../../../../../code/Clients/iOS/UI/PlayerPreview.swift)
