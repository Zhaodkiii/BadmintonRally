# 动画负责人

2026-11-25 · 编写人：动画负责人 · 状态：待验收

我负责确定球员在比赛镜头下应当呈现的动作意图、节奏和轮廓。我给动画师标出准备、启动、触球、制动和回位的观察点，在正式机位按正常速度审片，记录具体球次、遮挡和返修意见，并签署动作表现结论。

体育动作顾问复核步法与持拍合理性，绑定师和技术美术处理骨骼与导出问题，动画程序负责比赛中选片与同步。玩法程序核对击球事件；动画 QA 独立复验后，由制作负责人提交里程碑证据，体验放行由独立验收主任签发。

首次工作已核对 R34 样片验收记录和比赛入口，形成近身短挡与远身救球的判读条件。下一岗为动画师，检查人为动画 QA，正式比赛镜头的签字仍待取证。[M1 基线核查](任务/M1-基线核查.md)
