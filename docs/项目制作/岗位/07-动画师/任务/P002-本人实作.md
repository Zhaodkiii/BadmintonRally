# P002 · 近身短挡的制动发生在哪一段

**我先改备拍外开到迎球之间的转折。** 实测已经有减速，优先解决第三、四格之间拍框运动投影太小、前段外开反而更抢眼的问题。第一版试做把原脚本的 ready 平移增量从 (0.047, 0.015, 0.056) 米缩至 (0.024, 0.015, 0.028) 米，并将其衰减起点从 0.415 秒推至 0.450 秒，终点仍是 0.575 秒。第一次对照保留旋转、brake 和 tuck 的参数，以便判断调整备拍幅度和过渡时间是否奏效。该方案待另存候选场景验证。[原曲线与坐标](../../../../../assets/美术/女球员独立制作/R34动作样片/制作工具/近身短挡迎球.swift)

复算时取每个目标时刻最近的 CSV 行，同前一行的 bed_x、bed_y、bed_z 求欧氏距离，乘 120 得米/秒。相机投影可让世界空间的快速迎球在画面上只移动数像素，两种观察应同时留档。我的下一步是按以上参数导出同机位、同尺寸基线与候选版交动画负责人，QA 隐去版本标记，原速播放后分别标出减速帧。若候选仍早在备拍外开时就被标作制动，或看不出短送，则撤回这次改动。另核对 0.575 秒原拍床中心、有效框内接触与原地支撑。此次仅检查独立样片，实际比赛效果待真机录像。
