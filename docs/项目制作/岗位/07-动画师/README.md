## 第一项验收

同机位、同速度匿名播放近身短挡旧版和改版，去掉球与拖尾，请动画 QA 各标一次“拍头突然减速”的帧。再叠回带球侧面录像，以实际球头抵达拍床的时刻为零，比较两次提前或滞后的帧数。若改版仍把备拍峰读作制动，记录球次和误读帧退回；同时检查右鞋是否仍原地支撑。[本岗试做与验收顺序](项目理解与岗位能力.md)

## P002 本人实作

我对照 R34 近身短挡的六格原图和 120 Hz 实测表：拍床从 0.475 秒的 2.192 米/秒减到触球时的 0.587 米/秒，背面小图却难辨这一转折。下一稿先缩小备拍平移量、推迟其衰减起点，再由动画负责人和 QA 比较两个版本的盲标帧。[实作记录、原图与候选参数](任务/P002-本人实作.md)

## P005 正式比赛动作

我已将反手平抽的平衡臂预备、触球后短送和挥空后的持拍侧收回交 08 合入正式比赛。右手挥空 F92，球从露出肩侧的拍头下方经过；按键当帧仍难从背面单帧判读。下一岗以正常比赛尺寸做截断盲审。[本人制作、改前改后图和逐帧证据](任务/P005-本人实作.md)
