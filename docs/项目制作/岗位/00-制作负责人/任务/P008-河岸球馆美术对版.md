# P008 河岸球馆美术对版

目标画面是用户提供的木拱河岸球馆插画。用于比对的旧图是正式比赛中的[首拍截图](../../../../../assets/美术/球场场景设定/河岸球馆-比赛实景.jpg)。

| 旧实景和设定的可见差异 | 主责 | 在比赛机位看什么 |
| --- | --- | --- |
| 河景铺满正后方，草图正中应是有玻璃山墙的室内纵深，河与渡船在右侧开口 | 场景美术 | 远端球员身后有相对安静的承托色，两侧能看出不同空间 |
| 屋顶只剩上边缘几段梁，看不出连续拱架、细木纹、采光顶和悬灯 | 场景美术、制作负责人 | 多跨拱顶沿纵深缩小，旗绳有下垂，旗面有折线 |
| 店铺像封闭色块，台阶和坐席同色，树叶像球 | 场景美术、制作负责人 | 场边有近处花箱、中景店铺和真实阶梯；转移机位时道具按距离产生视差 |
| 蓝场面饱和度高，场线和人物站姿都太硬 | 镜头、角色美术 | 场线清楚，球与拍头在纹理前仍可见，两名球员各有支撑脚和外展的拍头 |

## 制作顺序

1. 锁定草图中的网柱、底线、木拱中轴和两侧空间关系，用正式比赛相机投影对位。二维画稿允许透视夸张，实景仍采用游戏的球场米制坐标。
2. 将美术按距离制作。演员、网、球、灯具、木拱、花箱和看台在世界坐标中摆放。把生成的图像拆为构件表面与远景，对店铺背面或侧面的需求按实际比赛视线决定。
3. 使用同一球次比较旧图、概念图和新构建。正常横屏、后场、换边和镜头过渡需能读出球路。将美术对比与玩法回归分列，同样的比分只能说明输入回放一致。
4. 使用 iPhone 18 Pro 模拟器录正式单打全局。整局录像、构建指纹和输入来源供独立验收；美术效果从运行帧判定。

相机匹配的依据可参阅 [Epic 相机校准说明](https://dev.epicgames.com/documentation/unreal-engine/camera-lens-calibration-overview)。本项目在 SceneKit 中用场地地标和回放取景落实这一原则。

## 生成素材

屋面使用内置 imagegen 制作蜂蜜色胶合木板的二维漫反射纹理，随三维屋面透视显示。生成方向为正投影木纹、横向长板、低对比水彩色差、细铅笔线和稀疏木结，避免烘入方向性光照。资源位于 `code/Clients/iOS/Resources/PavilionRoofGrain.jpg`。

## 实作和返修

独立建模的拱架、天窗钢斜撑、成对吊灯和沿廊旗绳围合球场。屋面图、左铺正立面及远端山墙分别映射至对应几何体。近侧店铺另有可见厚度、挑檐、柜台及垂藤。看台由踏步和木条构成，戴帽休息、撑下巴观赛和鼓掌三种坐姿占据不同排。花箱、植物和旗帜都在场外的实际深度。

第一次联合实拍中，店铺、花箱在 SceneKit 静态合并后丢失父变换，被错误放到球场中央，导致对手完全不可见。复验方式为在原来遮挡对手的首拍机位看实体运行画面，修复是在合批前将嵌套节点变换烘焙到共同空间。第二轮还调整开局机位，使网带回到画面约一半高度、前景底线回到可读范围。

球场以低饱和度蓝色颗粒地胶、细织网和接地阴影与环境绘画统一。近端球员采用暖珊瑚训练衫、青绿短裤、白袜和胶底鞋，远端球员采用浅砂色球衣。草图中的玻璃墙、河岸与商铺需要分别看其所在位置、视差、轮廓和笔触；人群与球员的画面精细程度另列，不因构图正确而默认达标。
