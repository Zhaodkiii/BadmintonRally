# P007 后场跑位和穿模复验

用户在 iPhone 试玩 P006 E 版时，发现人物跑到不合适的后场位置，有画面穿模。这个工单用固定来球复现站位和动作，逐项对照球托、拍床、头部和脚底。正式复验采用 iPhone 18 Pro 模拟器，输入为可重复的模拟按键。

| 岗位 | 复验内容 |
| --- | --- |
| 玩法程序 | 比较击球区前后站距、持拍侧留位和拦截时的脚速。覆盖左右手、正反手底角、追身和远位起步。 |
| 动画程序 | 用前后帧区分二维遮挡和三维穿入。晚按高球时分别测头部、拍杆和拍框，此外复查衣袖与鞋底。 |
| 独立验收 | 先冻结原版，保留同球日志和录像；使用候选版复跑后场专项及正式单打，复核确有拍床接触才改变球路。 |

正式模拟器启动参数 `-contactFrameReplay -rearCourtReplay`。再加入 `-rearLate` 可复现延后 100 毫秒的同组来球。专项回放会写入 `Documents/P007-后场.tsv`。正式比赛使用独立章程规定的首页至原生结算录屏。

## 已定位并复现

原跑位把双脚中心对准后场球的横坐标，并在触球前 140 毫秒再切一次深度。普通正手高球样本的脚位触球仍以 1.68 m/s 平移。修后正手为持拍侧留出 24 cm，48 个高球/底角样本在触球时停步。快平球远起步仍保留移动中接球。84 个固定球次修前修后皆能触拍，因此这项修复的实测收益是站姿与减速时机。[岗位实测与逐球表](../../09-玩法程序/任务/P007-本人实作.md)

独立验收用真实三角网格确认旧版晚按高球有拍杆穿脸、晚按反手底角有拍框或网线穿过头部。固定场景通过后，首个动画候选整局仍在实际后场准备阶段产生新的相交帧。独立验收将 0∶0、3∶1、8∶2 及近位反手平压延后样本退回重做。后续候选应同时经过专项和正式单打复查。

改用实际预计拦截点判断后场准备，保持拍床接触时刻和手臂长度。晚挥时，低位回球沿身侧随挥。独验在首个完整候选的近位正手平压延后样本 F140 发现握柄尾部沿轴深入衣服 22.8 mm。追加握柄尾端间隙后，带正式参数的 80 组、12,456 帧中所测七类交叉均为零。制作负责人用最终源码重新跑 84 组跑位与拍床回归，输出与玩法岗位逐球表相同。[动画实测](../../08-动画程序/任务/P007-本人实作.md)

独验再现了 3∶1 对手平抽造成的后场落点被底缘裁切。正常机位的纵向基准后移 45 cm，镜头横线保持水平。原失败球包含球托与羽裙的完整外轮廓，从越界 18.89 像素变为留边 7.20 像素。左右手两场离线正式单打和 80 组后场专项中，球与双鞋均保留在画幅内。[镜头逐帧数据](../../08-动画程序/任务/P007-近端落点构图.csv)
