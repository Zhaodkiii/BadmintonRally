# P002 制作负责人派工与收件

同一拍低球中，玩家按键、比赛计算触球、人物拍面迎球与屏幕上的球变向，可能分别发生在不同帧。我负责追踪这四件事能否在同一版本相互印证。制作组先交一轮可复查的工作证据，再由独立主任检查岗位交付。

| 本人负责的岗位 | 给定问题 | 接收成果的岗位 |
|---|---|---|
| 玩法设计 | 同一低球改变站距，如何区分近接、远接与挥空 | 动画、玩法程序和 QA |
| 动画负责人 | 比赛镜头里哪一帧最难读，怎样审片 | 动画师 |
| 角色美术 | 现有角色在比赛尺寸下哪个轮廓最需要处理 | 绑定、动画负责人 |
| 绑定师 | 拍柄、手掌与手腕的接点能否从现有资产复核 | 技术美术、动画师 |
| 技术美术 | 现有角色资产导入比赛时怎样确认版本、坐标和尺度 | 动画程序 |
| 体育动作顾问 | 一段真实录像中，能观察到哪些支持腿和随挥特征 | 动画负责人、动画师 |
| 动画师 | 一组现有画面中的预备、触球、收拍能否读清 | 动画负责人、QA |
| 动画程序 | 人物关节及拍床从哪里进入比赛，证据缺在哪一步 | 玩法程序、QA |
| 玩法程序 | 比较提前 100 与 50 毫秒按键的球次 | 动画程序、QA |
| 动画 QA | 独立重跑一组现有对照，留下可复现结果 | 制作负责人、独立主任 |

每岗自行选择、查阅材料，记录来源和自己的判断，并签收下一步。实际工单在各岗任务目录。候选包、录像、逐球日志必须能对应相同运行；单独样片不能证明比赛版已达标。

## 制作决定与交给下游的问题

技术美术在 Mac 重建比赛球员时看到的动画加载路径与 R34 成片不同。绑定师量到的腕缝、动画师测到的减速都只可用于对应素材。下一版先由动画程序记录正式角色是怎样生成姿势和拍面的，再由玩法程序对齐按键与出球，最后交 QA 复跑，不以重做手指模型作为首项修复。
