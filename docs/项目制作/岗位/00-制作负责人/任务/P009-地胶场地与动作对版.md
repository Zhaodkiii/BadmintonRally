# P009 地胶、场地和动作对版

P008 的正式截图中，近底线太低，远底线也太低，网后地板与辅助区没有形成草图的透视。地胶纹理过于均匀，人体脚下的椭圆影与四肢动作脱节。验收分开比较同站位的真实回放、统一画幅下的地标、取样材质，以及角色肩髋和拍头的角度。

| 制作工序 | 实际返修与证据 |
| --- | --- |
| 场地 | 从草图标出近远基线与网柱，求比赛相机。超宽屏保留两翼，按原图比例检查中央 16:9。见[镜头实测](../../08-动画程序/任务/P009-场地透视校准.md)。 |
| 地胶 | 独立生成整张手绘地胶，首轮上材质后比较颜色与局部明暗，再做色彩校准；地面之外的物体、球线、球员均独立绘制。见[地胶实测](../../05-技术美术/任务/P009-场馆专用地胶.md)。 |
| 接球准备 | 跨脚幅度、脚尖角度、外侧负重、持拍侧开肩、拍头与胸的距离共同变化。第二轮把非持拍手收到髋侧，迎球、起跳和挥拍时释放该权重。送测时八组三帧触拍用例通过。 |
| 人影 | 按世界光向将每帧脚、髋、胸、头、肘、腕和拍头投至地面，用一个半透明材质合并其投影，跟随角色横移和抬脚。模拟器回放负责复核实际画面。 |
| 场馆 | 场景美术用视锥投影配准建筑和场边陈设，另行保存阶段图及差距。见[场景美术记录](../../05-技术美术/任务/P009-场馆投影绘景.md)。 |

开球时的游戏站位取决于发球权与得分。不能把静态插画中的接球员固定画在左侧；参考构图应选真正处在相近阶段的一帧比较。真实球网的高度受游戏规则约束，若按手绘网带的像素高度硬改三维网高，会引入玩法与显示不一致。

## 实景返修顺序

- 第一版把绘景分配到屋顶曲面、端墙、临河开口、咖啡馆、两侧廊、近柱与铺面。在超宽屏外侧和地胶旁露出天空色，退回。
- 第二版补连续实体铺地与左右扩绘。开局构图成立，实拍仍看到人影有多余的半透明矩形。显式丢弃影形以外的片元，修正混合色后，影子随支撑脚和挥拍姿态变化。
- 后场镜头拉远到约 14.10 米时，屋檐与河岸分层边界显露；初次补顶还出现拉伸条纹。美术重接曲面边界，在上沿用扩绘屋梁接续天窗，重放发生问题的第 3,018 个比赛步。
- 同位接发姿势复查发现，双脚有宽度却把持拍侧脚放在了错误的前后位置。依据脚踝、颈髋、握点与拍床测点再次修正错步和侧倾。复查结果见[角色姿势记录](../../03-角色美术/任务/P009-接发角度返修复验.md)。

完整侧移与极端机位证据归入[独立验收记录](../../../../独立验收/00-验收主任/任务/P009-场景对版独立裁决.md)。减少动态效果机位沿用实体场馆，以适应不同的取景方向。手绘观众和远景陈设没有独立角色动画。
