# P008 河岸球馆场景美术复核

原草图中的红色咖啡馆占据近景一侧，屋架沿场地纵深重复，玻璃山墙使远端球员与来球从河岸景物中分离。旧版将店铺放在远端，近景缺少可读细节；河岸画位于整座球馆之后，从网中间也能看见水面，画面层次与草图有明显差距。

## 实测与边界

在 macOS SceneKit 使用比赛真实渲染器、相机和场地生成 1320 × 610 画面。首轮合批导致店铺和花槽出现在网前。停用合批的对照画面正确，确认原因为嵌套的空变换节点。修复后在实际执行合批的画面中，咖啡馆、花槽均归位，远端球员可见。终版模拟器整局另由独立验收执行。

近景店员和橱窗道具绘在店铺内部的同一立面，球场侧视角下能读到层次；若新增走入店内或环绕店铺的自由相机，应另行制作内室和店员模型。渡轮和河岸也属于远景绘画，现版本的视差来自店铺建筑、厂房玻璃墙与河岸之间的距离。
