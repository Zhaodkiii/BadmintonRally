# P009 场馆透视绘景
技术美术接单。目标是修正 P008 的远端山墙尺度、拱顶纵深、近处店铺与观众的素模观感。使用用户提供的草图和 P008 生成的无人绘景母版作为美术坐标，保留球网、来球、球员和比赛线的真实空间关系。每版使用同一正式 SceneKit 摄像机渲染，局部纹理在对应的立体表面取样。

## 资产结构与重建

场景由拱顶曲面、端墙、河窗、咖啡店、左廊、右廊、场外地面、近柱八组纹理网格组成。比赛时根据当前相机投影，各网格在世界坐标变换。网格深度由拱顶截面、侧墙、实地平面和河窗凹进量求出；邻面边界使用同一深度。场边店员和观众绘制在表面纹理中，属于受限运镜的 2.5D 绘景。没有独立头身动画，绕到他们侧后的自由镜头仍需完整模型。辅助广角模式使用立体模型版本。球员、球、网、场线及可玩地胶由正式三维比赛单独渲染。

两幅新增原画在 `assets/美术/球场场景设定/河岸球馆-P009侧翼扩绘.jpg`、`河岸球馆-P009顶棚扩绘.jpg`。内置 imagegen 使用上一轮无人母稿作编辑输入，第一次向左补店内、入口与植物，向右补阶梯、箱花和河滨；第二次将同一画幅向上补木拱钢撑与采光顶。保留原中轴、横向纵深和球场空场，场上人物、球以及球网独立。每一份扩绘均经特征配准再裁切入局部贴图。

在仓库根目录执行 `python3 code/Tools/build_hall_islands.py --output /tmp/river-rebuild` 可重建局部贴图。依赖 Python、NumPy 和 OpenCV 4.5 以上的 SIFT 接口。本轮在本机验证输出与 `code/Clients/iOS/Resources/RiversideHall.scnassets` 中的八张图、布局清单逐个字节相同。运行时使用 6.9 MiB 的局部资产与布局；三幅完整母画只保存在美术工作目录。
