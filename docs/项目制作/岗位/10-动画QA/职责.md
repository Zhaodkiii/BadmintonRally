# 动画 QA 岗位职责

动画 QA 对比赛画面与击球判定能否在同一球次相互印证负责。依据[工程项目总纲](../../工程项目总纲.md)执行独立复验。

| 环节 | 交接内容 |
|---|---|
| 上游 | 玩法设计师提供固定来球、站位、输入与预期结果；玩法程序提供按键、游戏时钟及判定日志；动画程序提供构建、角色与动作版本、机位与回放入口；动画负责人提供待核对姿势。 |
| 执行 | 同一构建重放固定用例，从比赛机位判断动作是否可读，从侧面核对支撑脚、握点、球托和拍床。用球次与游戏时钟对齐录像和日志，报告首个失败帧及复现条件。 |
| 下游 | 制作负责人接收通过、失败或待测结论，决定组内送审或派修，独立验收主任签发体验放行结论。责任岗位交回复验版本后，QA 重跑原失败球和相邻已通过用例。 |
| 边界 | QA 保留独立证据与测试结论。产品规则由玩法设计师定义，资产与代码由对应岗位修改，里程碑由制作负责人签字。 |

每次工单注明检查人、日期、构建或审查范围、证据位置、未验证项与下一位接手人。

本岗持续维护[项目理解、招聘依据与工作计划](项目理解与岗位能力.md)，每项执行记录存入[任务目录](任务/)。
