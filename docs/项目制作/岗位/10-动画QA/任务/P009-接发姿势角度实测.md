# P009 接发姿势角度核对

原画与 V3 模拟器正式单打 1∶1 左区准备接球各取 1672 × 941 中心画幅。图的横轴向右、纵轴向下。人工从两张图分别取鞋面中心、衣领中点、腰带中点、握点与拍床中心；估读误差约 3–6 像素。两帧的球赛进展与站位不同，因此只对比与准备动作直接相关的角度和尺度比。[轮廓标点，原画在左、实景在右](P009-证据/V3-参考左与接发右-鞋胸拍测点.jpg)

| 测量 | 原画 | V3 接发帧 |
| --- | --- | --- |
| 头发最高点至最低鞋底 | 约 375 px，占画高约 40% | 约 307 px，占画高约 32.6% |
| 两鞋中心横距除以人物高 | 208/375，约 0.55 | 162/307，约 0.53 |
| 持拍脚相对另一脚的画面高度 | 低约 26 px | 高约 14 px |
| 腰带到衣领的投影轴，向持拍侧偏离竖直 | 约 25° | 约 12° |
| 握点到拍床中心的投影轴，向外偏离竖直 | 约 40° | 约 27° |

V3 的脚宽已接近画稿，仍能看见脚的前后关系反向。若专门制作用于后场预备接球的画稿姿态，建议沉髋时持拍脚略靠近镜头，并使髋到胸之间的横向偏移增大；拍头再向持拍侧打开。接杀和发球分别保持适合来球的站位。只有两脚投影的前后关系得到实测，单幅图无法恢复足底的真实三维距离。胸部投影轴同时受躯干侧倾和前倾影响；复验宜回到同一游戏机位。主挥与触球应另用比赛球次验证。
