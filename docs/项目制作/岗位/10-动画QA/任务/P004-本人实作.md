## 本人实施与使用

Debug 中使用专用无标签回放。每种固定输入在背面各播两次。前四段覆盖四种不同输入，后四段换序重放。每段从发球准备开始，播放 128 个 60 Hz 游戏步，显示时钟按照设备屏幕刷新推进；超时则补算游戏步，并记录缺失的显示机会。每球之间有相同设置的短黑场。比赛内关闭球及球拍拖尾、拦截点和落点标记；画面无拍号、结果、手别、时刻、比分或教学文字。全部结束并成功写盘后显示中性片尾“播放结束”。侧面回放仅供解盲后定位。旧 P003 慢放诊断及其三个测试入口继续保留。[Debug 回放](../../../../../code/Clients/iOS/App/ContactFrameReplay.swift) · [专用真机用例](../../../../../code/Tests/UI/ContactFrameReplayTests.swift)

从仓库根目录执行下列命令。使用新的 xcresult 路径，避免覆写原录像。两支测试自动传入盲审参数；单独手动启动时使用 -contactFrameReplay -contactBlind，侧面再加 -contactSide。

```sh
xcodebuild test -project code/BadmintonRally.xcodeproj -scheme BadmintonRally \
  -configuration Debug -destination 'platform=iOS,id=00008150-001674201E53C01C' \
  -parallel-testing-enabled NO \
  -only-testing:ClubFlowTests/ContactFrameReplayTests/testBlindBackView \
  -only-testing:ClubFlowTests/ContactFrameReplayTests/testBlindSideView \
  -resultBundlePath "/tmp/P004-blind-$(date +%s).xcresult"
```

真机录屏保留原速与原画幅，以黑场切分。提交首次观察前只播放背面前四段一次，原速、静音。逐片写“挥空／回击／看不清”，说明拍框与头肩的相对位置，以及何时看见球与拍面分离或贴近。后四段供一致性检查；四个重复片段不增加独立人数。若只凭回球飞向猜对，保留原话并与能看清接触区分开。初次观看侧面、慢放、几何表或答案的人另列。

设备 Documents 中生成 P004-back-timing.json、P004-side-timing.json，逐片记录已执行按键、游戏步、缺失的显示步数和触球附近是否跳步。交 QA 检查每机位八段、每段 128 步、均有按键。触球附近跳显示步或录屏帧率不足以判读时，记录对应片号并重录；显示回调仅反映游戏侧的提交节奏，还要检查实际视频帧率与可读性。弃用 P003 带结果标签的慢放片。独立验收员保留首次原话，制作负责人登记结论。

答案由本岗另存，承诺文件 SHA-256 为 212dcc2e456ee73c61497d311bfbd5e266566663ccac9fd35bac8a50310e1bd4。待所有首次记录交回，QA 核验哈希后解盲。首版设备试跑发现 SceneKit 预载对象类型错误；已去掉该预载。应用测试改用写盘后出现的中性片尾确认完成。此工单先交可部署构建与复验数据，设备录像和观察者判读分开登记。

## 设备实测跟踪

首候选两项盲审 XCTest 在 iPhone 通过。背、侧两机位均记录 8 次按键、1024 个游戏步。背面未跳显示步；侧面累计补算 3 步，均在接触检查窗之外。以视频亮暗边界分割，两个机位各出现 8 段连续比赛画面，每段 65 个编码画面、时长 2.133 至 2.135 秒；触球区相邻视频时间戳间隔约 33.3 ms。可据原速画面判断整体观感，精确接触时间仍查同步几何。

08 修复后场裁脚后的终候选，再次使用原三帧夹具独立编译运行，24 行 CSV 与 P003 冻结表逐字节相同，退出 0。此次测试的 SpatialCourt.swift SHA-256 前十二位为 83a1a2c65be1。[终候选三帧](P004-证据/终候选三帧.csv)

终候选在 Dream話 iPhone 的三个 XCTest 均通过，分别覆盖背面固定回放、侧面固定回放和从正式比赛入口触发一次硬件音量键。两机位时序各有八段，各段 128 步和一次合成按键；背面总计补算 0 步，侧面总计补算 2 步，两机位均未在触拍前中后三帧跳显示步。末步显示期限背面 2.1223–2.1299 秒，侧面 2.1190–2.1280 秒。实体键用例记录计数变化，固定四球回放用的是预设输入。[真机测试摘要](../../00-制作负责人/任务/P004-真机送审/final-真机测试.json) · [背面显示时序](../../00-制作负责人/任务/P004-真机送审/final-back-timing.json) · [侧面显示时序](../../00-制作负责人/任务/P004-真机送审/final-side-timing.json)
