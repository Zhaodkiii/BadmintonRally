# P003 动画 QA · 三帧测球托与拍床

2026-11-25，执行、自检与返修跟踪人为制作线动画 QA。验收人为独立玩法与视觉验收员。范围为 Mac 上调用正式比赛同款 Rally、CourtScene、按键候选判定，并无新增 iPhone 比赛录像。

## 取样与复跑

我新增一个独立夹具，使用固定的中场“身体侧面平快球”，与 V002 同样的反手平抽输入、60 Hz 游戏时钟、来球拦截时刻二分法。分别测左右手的提前 100、提前 50、正常 0 毫秒与强制超距，共 8 球。远位用例每帧固定附加的球员坐标；同手各用例共用同一来球。每球保留按键前一帧、按键帧及后一帧，世界坐标单位为米，另存来球标记和累计回球数。[夹具](../../../../../code/Tests/Checks/ThreeFrameContact.swift)

从实际绘制的球托球体取中心与半径（65 mm），从近端人物 StringBed 的环面取内缘与世界变换，得到有效椭圆盘。球托中心投影在盘外时，用二分求最近椭圆边界，将横向距离与法向距离合成，再扣除球托半径。净距为正表示分离，负数表示球体与盘重叠。CSV 包含盘中心、法线、两个有向半轴、肩、肘和腕。独立计算不读取生产判定返回的几何布尔值。姿态回归对固定的普通站位平抽用例检查相邻帧肘、腕位移是否超过 200 mm；该项目筛查线用于发现单帧跳变，常规 −50 与 0 毫秒对照的腕位移为 21.8 至 42.9 mm。

使用 macOS arm64 与 Apple Swift 6.4.2。以下从本记录所在的“任务”目录执行。压缩包保存同一份测试源码及各轮编译输入。“before”使用旧的按键 API；“first”、“second”和“final”使用正式比赛的拍床验证回调。

```sh
qa_dir=$(mktemp -d)
tar -xzf P003-证据/复现源码.tgz -C "$qa_dir"
for version in before first second final; do
  case "$version" in
    before) set -- -D BASELINE_CONTACT ;;
    *) set -- ;;
  esac
  swiftc "$@" "$qa_dir/$version/"*.swift "$qa_dir/ThreeFrameContact.swift" -o "$qa_dir/check" || break
  "$qa_dir/check" > "$qa_dir/$version.csv"
  echo "$version 退出状态 $?"
done
```

## 可直接执行的真机复验

1. 装同一候选包，记录构建、角色版本、设备、帧率和系统；从“场景采集 → 中场 → 固定来球 → 身体侧面平快球”选择正手侧来球，保持目标与力度一致，分别用左右持拍手尝试反手平抽。通过游戏时钟记录按键相对同球预计拦截时刻的实际偏移，人工没有按到规定档位的球保留实测偏移，再补目标用例。
2. 各手依次收集提前 100、提前 50、正常三档及明显超距。超距测试记录实际站位；界面的“远位起步”可能在按键前已跑入范围，必须按实测站位分类。预期提前 100 和超距只产生一次挥空并保持来球；提前 50 与正常档产生一次回球。
3. 每球提交同一个球次的正式背面原速录像、匹配时钟的侧面回放、按键与判定、游戏飞行方向、回球计数，以及按键前中后三帧几何。侧面复演须使用同球事件与站位。另从首页“开始比赛”打一个回合确认生产入口。缺少球次、同步日志、可复演机位时标为缺证。由独立委员会检查玩家能否读懂挥空与恢复。
