## 首轮逐球交接

A/B/C 均取同侧同一条网前低点下落球，固定持拍手、目标“轻托回网”和目标方向。玩法程序提供以同一游戏时间为基准的来球参数或逐帧坐标。QA 先核对三条世界轨迹，再对照下表。设置页的“中场 → 接杀防守 → 接杀挡网”另录为短挡动作参考。

| 球次 | 只改变的条件与操作 | 判定及画面验收 |
|---|---|---|
| A 近身 | 以近身起点进入，在可达窗口轻挡并按一次音量键 | 双脚站稳，屈肘短挡；按键触发一次尝试，拍面接球后球过网，随后回位。 |
| B 远半步 | 保留 A 的来球和按键相位，将站位移至需要跨一步仍可达的位置 | 先跨步压髋，再伸拍触球，回蹬恢复。记录角色起点和触球位置。若现有远位起点不满足条件，交玩法程序复现所需距离。 |
| C 够不到 | 从 B 起点，在角色仍明显不可达时提前按一次 | 记录按键时的角色和球，核实拒绝原因。画面应可见收拍和来球继续飞行。 |
| 输入回归 | 复跑 A，一球挥拍但不按键，一球长按后松开，再测同球重复按与暂停恢复 | 比较按键与判定次数、出球轨迹和参考图时序，确认无按键无回球，一次按下最多一次尝试。 |

QA 每球交回构建与角色版本、来球参数、起点、按键游戏时刻、接受或拒绝原因、录像及接触前后帧。另从首页“开始比赛”完成一回合确认生产入口。玩法设计师复核 A/B/C 的意图与实际球路，制作负责人汇总签字。当前缺少可重放的 A/B/C 球次、同轨迹比较、实体音量键和比赛画面证据。
