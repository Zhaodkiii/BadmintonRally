# 玩法设计师怎样判断一拍打得值

我希望玩家在正式单打中看到后场对手尚未回中，就能决定把一颗低球轻托过网，逼他往前赶。若自己还在跨步救球，则可以向上挑深，争取从弓步回到准备位。回球落在对方场内且未被接起才赢下这分。对方接起时，仍应能从他的拦截位置与自己的恢复时间看出上一拍赚到了什么。iPhone 独立完成从发球到结算，电视呈现比赛画面，Mac 留下开发复盘证据。[工程项目总纲](../../工程项目总纲.md) · [参考作品拆解](../../../参考研究/SwitchSports羽毛球拆解.md)

我的工作是给玩家的选择设计可推翻的判断。锁同一低球、站位、持拍手和按键相位，先只改变挥动，分别轻托与挑深；记下球的过网净空、落深或对手拦截点、对手触球时间，以及己方恢复可行动的时刻。若上挑的飞行更短、己方仍无回位时间，或者短托未将原在后场的对手调向前，就收回这组球能表现战术差异的判断。横向另测，锁住力量和时刻，只反转按前横挥。若左右落点始终同侧，需查朝向与映射。[独立研究验收](../../../独立验收/00-验收主任/任务/R001-团队理解验收.md)

## 招聘原页与本作试做

2026-11-25 打开 2K 授权的 Greenhouse 岗位原页。雇主为 2K，团队为 2K Sports Lab，职位为 **Senior Gameplay Designer**，地点 Burnaby，页面列明现有空缺并显示申请表。雇主要求设计逐秒发生的体育体验，理解系统设计，与动画及工程团队协作、维护玩法优先级、协同 QA 测试。岗位还要求带过七人以上的功能团队。招聘范围为体育游戏，页面未指定羽毛球或手机体感。[2K 招聘原页](https://job-boards.greenhouse.io/2k/jobs/7512739003)

项目自定试做题为“同一颗低球的三个站距”。先写清近身能挡、远半步需跨、再远够不到时玩家应看到的脚步和球路，再让独立人员用提供的球次重放。三球保持同一世界轨迹、持拍手、输入和按键时刻，唯一变量是起始站位。C 球在同一时刻超距，收拍后球继续飞行。早按另开用例。这样可以把招聘所说的逐秒玩法、动画协作和 QA 测试落实为同一个可裁决的问题。
