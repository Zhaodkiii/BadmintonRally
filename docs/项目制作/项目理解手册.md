# 晚风球社 · 全员项目理解手册

**当前 iOS 运行与测试目标**　仅使用 iPhone 18 Pro 模拟器（iOS 27.2），禁止使用个人实体手机。运行参数与硬件项记录方式见[项目设备约定](运行与测试设备.md)。

**总目标**：完成可以用 iPhone 握持挥拍、可投屏电视、可连续打完整场单打的原创 3D 羽毛球游戏。以 2022 年 Nintendo Switch Sports 羽毛球的操作直觉、角色动作可读性和回合节奏为体验参照。球员选择短、深、左、右和进攻时机；每个选择要真实改变对手下一拍。制作负责人是本项目主线程，最终体验放行由独立验收委员会裁决。[工程项目总纲](工程项目总纲.md) · [参考游戏研究](../参考研究/SwitchSports羽毛球拆解.md)

## 每位员工应能解释的一分球

发球准备 → 选择线路和力度 → 来球飞行与预判 → 人物跑到可拦截区域 → 玩家在挥动中按音量键 → 检查该时刻能否触达 → 合理接触后改变球路或挥空 → 恢复到下一拍 → 得分与换发。角色跑到预计拦截点附近等待，最后微调。球在身前高点可以下压也可收力打短；球在网带以下仍可上挑，勉强下压可能撞网。力度应覆盖中场，挥向应能产生左右连续变化。

同一颗低球的三种站位是全员理解题。A 近身，保持脚下稳定，前臂短送；B 远半步，跨步、压髋、接触并回蹬；C 已超距，完整挥空，原球继续飞。三次固定来球轨迹、挥动输入和按键时刻；另做早按、晚按、无按键、长按和连续两拍。若把时间和位置同时换掉，就不能据此分辨失败原因。

## 系统如何协作

| 子系统与主责 | 读取什么 | 向下一岗交付什么 |
|---|---|---|
| 输入与判定 · 玩法程序 | 按键单调时间、历史手机姿态、角速度和去重力加速度、当时的球与角色位置 | 唯一球次/尝试、命中或拒绝原因、触点、出射方向与速度。无按键的抖动不产生回球。 |
| 比赛角色 · 动画程序 | 来球、预计拦截点、当前步态、持拍侧、击球事件 | 同一时钟下的根节点、支撑脚、拍床平面和有效面积、姿势阶段。超距动作受身体可达性约束。 |
| 角色与运动 · 美术/绑定/动画 | V2 原型、真人录像、动作设计、统一坐标和版本 | 真正进比赛的资产、触球和落脚标记、比赛距离下可读的准备与恢复；同时提交极限姿势。 |
| 开发采集 · 程序与 QA | 同一球次的目标回法、来球、IMU、按键、实际球路、角色与摄像头画面 | Mac 上带版本和时钟映射的逐球复盘包。玩家意图、推断球种和实际结果分别记录。 |
| 验收 · 制作 QA 与独立委员会 | 构建、日志、失败球、比赛及侧面画面 | 制作侧复现后送审，独立团队可判通过、退回重做或退回补证；新版本用原失败球重测。 |

## 已知事实与制作顺序

R34 角色有四段独立成片，源资产与 iPhone 预览资源已有哈希核对。正式比赛走 SpatialCourt。V002 的 90 组时序夹具可复跑；反手平抽提前 100 ms 的拍尖至球距离约 31 cm，仍需有效拍床和同帧画面判断是否真正接触。制作侧不能把夹具通过报成游戏达标。[独立裁决](../独立验收/00-验收主任/任务/V002-裁决.md)

| 里程碑 | 负责人接收的产物 | 何时可以向下扩展 |
|---|---|---|
| M1 一颗低球 | 同构建 A/B/C 的输入、有效拍床、原速正侧画面和下一拍 | 可以分别解释站稳、跨步和挥空，正式入口重放结果一致。 |
| M2 三类动作过渡 | 头顶进攻、反手底角和网前高点，接上跑动、落地和下一球 | 无特效能辨击球侧和支撑脚，合理挥空也有收拍。 |
| M3 专项覆盖 | 九种接球场景、27 项目标回法、四种发球；左右手及力度深浅对照 | 同来球有战术选择，方向、弧高、落深与输入可解释；不合适的回法可失败。 |
| M4 整场体验 | 真机及投屏单打、计分与换发、连续回合、性能与延迟、新手反馈 | 复盘能解释失败，独立委员会按版本签核。 |

## 岗位本人如何证明理解

每个岗位读原始资料和本岗已有证据，用一个实际球次或动作解释贡献，写出一个可能证明自己判断错误的实验。招聘页证明业界要求的技能；本岗已会什么，由产物、复现命令和独立测试证明。人员招聘的年限、软件、学历或真人教练资质，只在有确切来源时注明适用范围。智能体身份不等同具备真人从业资历。源页下线、产品契约改变、工作退回或能力验证有新证据时，由岗位本人更新自己的手册并追加日期。[岗位原件和工单台账](岗位/README.md) · [制作负责人派工原件](岗位/00-制作负责人/任务/P001-全员派工.md)
