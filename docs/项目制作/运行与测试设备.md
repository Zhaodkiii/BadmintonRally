# iOS 运行与测试设备

自 2026-11-25 本次设备要求起，BadmintonRally 的 iOS 客户端统一在这台模拟器运行。适用于 Xcode Run、命令行启动、调试、UI 测试、游戏回放、截图录屏、QA 和独立验收。制作负责人、所有岗位智能体和自动化执行相同约定。

| 项目 | 指定值 |
|---|---|
| Xcode Scheme | BadmintonRally |
| 运行目标 | iPhone 18 Pro（iOS Simulator） |
| 系统版本 | iOS 27.2 |
| 本机模拟器 UDID | `89B4EB3F-3B23-4F9F-AA91-5D3AC77016A8` |

在 Xcode 顶部运行目标中选择上述模拟器。命令行显式指定同一 UDID，避免名称匹配到其他设备。以下命令从项目根目录执行。

```sh
xcrun simctl list devices available
xcodebuild -project code/BadmintonRally.xcodeproj -scheme BadmintonRally -destination 'platform=iOS Simulator,id=89B4EB3F-3B23-4F9F-AA91-5D3AC77016A8' -parallel-testing-enabled NO test
```

目标不可用时，记录阻塞并恢复该模拟器。禁止自动切换到其他设备，禁止向用户的实体 iPhone 安装、启动、调试、录屏或运行测试。模拟器无法验证的真实 IMU 挥动、系统实体音量键事件与硬件输入延迟，登记为“模拟器无法验证”；回放或注入输入须标明来源。Mac 上的开发工具、离线数据分析和 RallyCapture 仍在 Mac 运行。

后续工单记录模拟器型号、系统、UDID、构建、输入来源及实测范围。生效前的 iPhone 17 Pro 录像、真机裁决和部署记录仅用于历史对照；旧工单中的真机复验步骤不作为后续派工指令。
